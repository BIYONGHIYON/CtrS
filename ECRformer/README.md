# ECRformer · SAR 기반 광학 영상 구름 제거

SAR 2밴드와 구름 낀 Sentinel-2 13밴드로 구름 없는 13밴드 광학 영상을 복원합니다. RGB 그림은 표시용이며 분광 성능은 전체 밴드 지표로 확인합니다.

## 최근 완료 평가 · 겨울 두 번째 부분 미세조정

첫 번째 부분 모델을 두 번째 부분에 미세조정한 뒤 **같은 test 패치 784개**로 전후를 비교했습니다. best epoch는 2(0-based)입니다. 각 겨울 부분은 한 test ROI의 패치이며 784개 독립 위성 장면을 뜻하지 않습니다.

| 지표 | 미세조정 전 | 미세조정 후 | 차이(후 − 전) |
| --- | ---: | ---: | ---: |
| RMSE ↓ | 0.05518 | 0.05146 | −0.00372 |
| MAE ↓ | 0.03932 | 0.03661 | −0.00271 |
| PSNR dB ↑ | 25.245 | 25.888 | +0.643 |
| SAM ° ↓ | 11.478 | 10.779 | −0.698 |
| SSIM ↑ | 0.81873 | 0.82994 | +0.01121 |
| LPIPS ↓ | 0.48422 | 0.47428 | −0.00994 |

[상세 보고서와 평가 근거](docs/experiments/winter_half2_finetune.md). 동일 조건의 전후 차이만 개선의 근거로 사용합니다.

### 실제 테스트 이미지 비교

왼쪽부터 **SAR · 구름 입력 · 미세조정 전 예측 · 미세조정 후 예측 · 정답**입니다. 보관된 패치 0~3의 그림을 재사용했습니다. RGB는 0-based 밴드 `(3,2,1)`, 밝기 배율 3.0입니다. 일부 예시이며 사전에 선정한 독립 장면 5개라는 기록은 없습니다.

![겨울 두 번째 부분의 같은 패치 4개: SAR, 구름 입력, 미세조정 전후, 정답](reproduction/winter_half2/comparisons/before_after_0000_0003.png)

잔여 구름·흐림도 함께 확인해야 합니다. 평균 지표 개선만으로 완전한 구름 제거나 분광 복원을 주장하지 않습니다.

## 최근 학습 분석 · spring 고정 6,000개

2026-10-04 실행은 epoch 8에서 최적 검증 손실을 기록한 뒤 epoch 16부터 발산하고 epoch 18 이후 조기 종료됐습니다. 정상 종료 코드와 학습 안정성은 별개입니다.

| validation 지표 | best epoch 8 | 마지막 epoch 18 |

| MAE ↓ | 0.022640 | 64.329369 |
| PSNR dB ↑ | 30.030531 | −36.421108 |

겨울 test와 직접 비교하지 않습니다. [봄 실험 요약](docs/experiments/spring_subset6000.md)에서 근거와 원인 후보를 확인할 수 있습니다. 봄 예측 그림과 독립 test 평가는 아직 미확보입니다.

## 다음 실행 준비 상태

`train_stable.py`는 lr 1e-4, 검증 정체 기반 감소, FP32 손실·검증 지표, 배치별 진단과 FP16/FP32 출력 비교를 지원합니다. CPU 단위 테스트 8개를 통과했지만 **이 설정의 실학습·성능 개선은 미검증**입니다. 이번 정리에서는 학습·추론을 시작하지 않았고 서버 코드도 수정하지 않았습니다.

앞으로 `research/ecrformer-stable-training` 브랜치에 계속 커밋하고 열린 PR을 업데이트합니다. main 병합은 사용자가 진행합니다.

## 결과 보관

기존 `reproduction/`의 지표·이미지·평가용 가중치는 유지합니다. 원본 TIFF, 새 대용량 checkpoint, 원시 로그와 전체 NPZ는 Git에 추가하지 않습니다. 미래 결과는 [보고서 양식](docs/experiments/template.md)으로 조건·전후 지표·곡선·사전 고정 사례·가중치/코드 식별자를 연결합니다. 없는 과거 자료는 미확보로 표시합니다.
