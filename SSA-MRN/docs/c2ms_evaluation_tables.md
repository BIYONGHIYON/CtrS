# C2MS와 원본 SSA-MRN의 데이터셋·시드별 평가 수치

성능 53번(QB)과 54번(GF2·WV3·WV2 전이)의 보존된 평가 수치를 한곳에 정리했습니다. 원본은 SSA-MRN K4(C0), C2MS는 원본에 W2 병렬 가지와 축척 혼합 학습을 적용한 현재 기준 모델입니다. 두 실험의 실제 실험자는 이병현입니다.

[루트 README의 원본 대비 개선](../../README.md#원본-대비-개선) · [53번 보고서](../experiments/performance/53_scale_mixed_training/README.md) · [54번 보고서](../experiments/performance/54_multi_sensor_scale_mixed_training/README.md)

## 읽는 방법

- 각 시드 값은 해당 데이터셋 test 20장의 평균이며, 3시드 평균은 시드 42·43·44의 산술평균입니다. 서로 다른 데이터셋의 수치는 합산하지 않았습니다.
- 각 모델은 원래 축척 validation으로 선택한 best 가중치를 사용했습니다. QB 원본은 기존 실험의 같은 시드 가중치를 재사용했고, GF2·WV3 원본과 C2MS는 54번에서 학습했습니다. WV2는 WV3 학습 모델을 그대로 적용한 전이 평가입니다.
- PSNR 단위는 dB, SAM은 도(°), FR 관측 RMSE는 DN입니다. PSNR·SCC·Q2n·QNR은 높을수록, SAM·ERGAS·관측 RMSE·Dλ·Ds는 낮을수록 좋습니다. 표는 소수점 넷째 자리로 반올림했습니다.
- GF2는 10bit 데이터지만 보존된 평가의 PSNR peak는 다른 센서와 동일한 2047입니다. 따라서 GF2의 절대 PSNR은 peak 1023 기준보다 약 6 dB 높으며, 센서 간 절대 PSNR을 그대로 비교하지 않습니다.
- RR은 정답 기반 주 평가입니다. RR2·FR_WALD는 열화로 만든 정답 기반 보조 평가이며, 실제 원래 해상도 FR에는 정답이 없습니다. FR 관측 RMSE는 출력의 관측 일치 오차입니다.
- SCC·Q2n과 FR QNR·Dλ·Ds는 참고 지표입니다. 개선 판정은 [v2.3 기준](judgement_criteria.md)을 따르며, FR QNR·Dλ·Ds를 판정에 사용하지 않습니다.
- 새 학습이나 재평가 없이 두 실험의 `evaluation_v2_3.json`에서 값을 추출했습니다.

## 근거와 해석의 범위

- QB: [53번 평가 JSON](../experiments/performance/53_scale_mixed_training/results/evaluation_v2_3.json)의 `models.*.mean`과 원본 대비 `judgements`를 사용했습니다. 53번의 F1·C2·F1MS 및 TTA 실험은 현재 기준 모델의 원본 대비 비교 범위에서 제외했으며, 해당 보고서에 보존되어 있습니다.
- GF2·WV3·WV2: [54번 평가 JSON](../experiments/performance/54_multi_sensor_scale_mixed_training/results/evaluation_v2_3.json)의 `models.*.targets.*.mean`과 원본 대비 `judgements`를 사용했습니다.
