**변경 내용:** 기준 모델의 어느 부분을 어떤 연산으로 바꿨는지 작성합니다.

## 1. 목적과 상태

해결하려는 문제와 개선 가설을 설명합니다. 마지막 확인 시각과 학습·평가 상태를 구분합니다.

## 2. 변경한 구조와 비교 조건

기준선 → 변경 위치 → 바꾼 연산 → 기대 효과 순으로 설명합니다. 데이터·분할·실제 K·시드·학습량·배치·장치·정밀도·손실·가중치 선택 기준을 표로 기록합니다.

<a id="results"></a>

## 3. 정량 결과

validation과 RR·FR test를 구분합니다. 기준선·후보·차이를 표로 작성하고 전체 장면 수와 지표 정의를 기록합니다.

## 4. 기준선 대비 차이와 해석

동일 조건의 기준선과 비교합니다. 이전 실험과 조건이 다르면 직접 비교할 수 없는 이유를 설명합니다.

<a id="graphs"></a>

## 5. 학습·평가 그래프

실측 학습·validation 곡선과 기준선 대비 그래프를 본문에 표시합니다. 없는 기록을 추정하지 않습니다.

<a id="images"></a>

## 6. 결과 이미지

고정한 서로 다른 5장면의 LR MS · PAN · 예측 · 정답을 표시합니다. 장면 ID와 표시 대비·확대 조건을 설명합니다. 없는 과거 예시는 미보관으로 기록합니다.

<a id="evidence"></a>

## 7. 재현 자료

실제 best/latest, 전체 지표, 학습 기록, 설정·소스 snapshot·해시 manifest를 연결합니다. 긴 SHA와 기반 브랜치를 본문에 나열하지 않습니다.

## 8. 개선 여부와 다음 단계

개선 / 부분 개선 / 개선 없음 / 판단 보류 / 비교 기준 / 성능 비교 아님 중 하나로 판정하고 근거와 한계를 설명합니다. 후보 선정과 최종 채택을 구분하며 다음 확인 항목을 적습니다.
