`research/<분야>/<번호>_<실험명>/README.md`에 작성합니다. 복사한 보고서의 전체 실험 목록 링크는 `../../../README.md#experiments`로 맞춥니다. 실험 등록 시 catalog의 `research_track`·`experimenter`와 해당 연구 페이지·두 README의 표를 함께 갱신합니다. 결과 보관 시 해당 폴더의 manifest.json을 갱신합니다.

**연구 분야:** SSAI 개선 / 가변 배율 확장 / 기존 성능 개선 중 하나를 적습니다.

**실험자:** 실제 수행자를 적습니다.

**변경 내용:** 기준 모델의 어느 부분을 어떤 연산으로 바꿨는지 작성합니다.

## 1. 목적과 상태

해결하려는 문제와 개선 가설을 설명합니다. 마지막 확인 시각과 학습·평가 상태를 구분합니다.

## 2. 변경한 구조와 비교 조건

기준선 → 변경 위치 → 바꾼 연산 → 기대 효과 순으로 설명합니다. 데이터·분할·실제 K·공간 배율·시드·학습량·배치·장치·정밀도·손실·가중치 선택 기준을 표로 기록합니다.

SSAI 연구는 바꾼 연산과 대조군을 명시합니다. 가변 배율 연구는 학습/평가 배율, 입력/출력 크기, 본/미학습 배율, 데이터 열화·보간·정렬과 단일/배율별 모델 여부를 추가합니다. 기존 성능 개선은 해당 변경 외 조건을 어떻게 맞췄는지 설명합니다.

<a id="results"></a>

## 3. 정량 결과

validation과 RR·FR test를 구분합니다. 가변 배율 연구는 배율별로 결과와 대조군을 표시합니다. 기준선·후보·차이를 표로 작성하고 전체 장면 수와 지표 정의를 기록합니다. [판정 기준](judgement_criteria.md)의 RR 주 판정과 RR2·FR_WALD·FR 관측 일치 보조 판정 값을 함께 적고, QNR·Dλ·Ds는 참고로 표시합니다.

## 4. 기준선 대비 차이와 해석

동일 조건의 기준선과 비교합니다. 이전 실험과 조건이 다르면 직접 비교할 수 없는 이유를 설명합니다.

## 5. 학습·평가 그래프

실측 학습·validation 곡선과 기준선 대비 그래프를 본문에 표시합니다. 없는 기록을 추정하지 않습니다.

## 6. 결과 이미지

풍경이 다른 고정 6장면(QB RR test 0-based 0·1·3·7·14·17)에서 현재 기준 모델과 후보를 비교합니다. 장면마다 ① 원본 크기 비교(LR MS · PAN · 기준 · 후보 · 정답, 기준·후보 오차 지도)와 ② 확대 비교(후보 개선이 가장 큰 64×64 창, 정답 전체 · 정답 · 기준 · 후보 · 기준 오차 · 후보 오차)를 `common/result_images.py`로 만들어 표시합니다. 장면 풍경, 장면 PSNR, 확대 창이 후보에 유리하게 골라졌다는 점, 표시 대비 조건을 설명합니다. 없는 과거 예시는 미보관으로 기록합니다.

<a id="evidence"></a>

## 7. 재현 자료

실제 best/latest, 전체 지표, 학습 기록, 설정·소스 snapshot·해시 manifest를 연결합니다. 긴 SHA와 기반 브랜치를 본문에 나열하지 않습니다.

## 8. 개선 여부와 다음 단계

[판정 기준](judgement_criteria.md)에 따라 개선 / 부분 개선 / 개선 없음 / 판단 보류 / 비교 기준 / 성능 비교 아님 중 하나로 판정하고, 미달한 보조 판정 항목과 근거·한계를 설명합니다. 단일 시드도 모든 판정 항목을 통과하면 개선으로 표기합니다. 여러 시드는 같은 조건 대조군과 짝지은 전체 시드의 평균으로 판정하고, 시드 수·시드 ID·시드별 결과를 함께 기록합니다. 후보 선정과 기준 모델 교체를 구분하며, 기준 모델 교체에는 3시드 이상에서 평균 판정이 개선이어야 합니다. 다음 확인 항목을 적습니다.
