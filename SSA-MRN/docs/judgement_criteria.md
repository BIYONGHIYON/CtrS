# 성능 개선 판정 기준 (v2.4)

모든 연구 분야의 현재 실험 표에 이 기준을 적용합니다. **2026-11-04 사용자 결정으로 v2.4부터는 RR 지표(PSNR·SAM·ERGAS)만으로 개선 여부를 정합니다. 이전의 보조 판정 3개(RR2·FR_WALD·FR 관측 일치)는 기준에서 삭제했고, FR QNR·Dλ·Ds는 참고로만 보고합니다.** 기존 실험은 [성능 47번](../experiments/performance/47_ground_truth_criteria_reevaluation/README.md)의 보존된 측정값으로 [현재 표 판정](../experiments/performance/47_ground_truth_criteria_reevaluation/results/summary_v2_4.json)을 다시 계산하고, 47번 이후 실험은 각 실험에 보관된 RR 평균 차이로 다시 판정합니다. 47번에서 측정 전에 고정했던 v2 판정과 원본 수치, 이전 v2.3 집계는 보존합니다. 새 학습이나 추론으로 결과를 바꾸지 않습니다.

## 판정 항목

| 구분 | 시험 | 조건 |
|---|---|---|
| 판정 | RR: PanCollection RR test 20장 | 같은 조건 대조군 대비 시드 평균 ΔPSNR ≥ 잡음 문턱(단일 시드 0.06 dB, 2시드 이상 0.04 dB), ΔSAM < 0, ΔERGAS < 0 |
| 참고 | FR QNR·Dλ·Ds, RR SCC·Q2n | 판정에 쓰지 않고 보고만 함 |

FR QNR·Dλ·Ds를 판정에 쓰지 않는 이유는 다음과 같습니다.

- [성능 46번](../experiments/performance/46_fr_spatial_index_validity/README.md): QB에서 FR Ds(Toolbox 1.0·원 논문 방식 모두)가 정답을 모델 출력보다 나쁘게 채점했습니다. 이 지표로 거부권을 행사하면 실제로 좋아진 결과를 탈락시킬 수 있습니다.
- [성능 51번](../experiments/performance/51_fr_detail_index_validity/README.md): PAN 유사도로 FR 세부를 재는 지표 4개도 정답을 모델보다 나쁘게 채점했습니다(0/20장, 순위 상관 −0.62에서 −0.77).

54번 평가 코드의 `judge`와 그것을 쓰는 이후 실험의 평가 기록에는 이전 보조 판정 결과가 함께 들어 있습니다. v2.4 판정은 그 기록의 RR 평균 차이만으로 다시 정하며, 새 실험은 보조 판정 항목을 보고하지 않아도 됩니다.

## 시드 수와 집계

- 단일 시드도 RR 판정(잡음 문턱 포함)을 통과하면 **개선**으로 표기합니다. 개선 표기에 3시드 이상을 요구하지 않습니다.
- RR ΔPSNR은 잡음 문턱 이상이어야 합니다. 문턱은 성능 43번 C0의 RR 시드 표준편차(0.056 dB)를 시드 수의 제곱근으로 나눠 0.01 dB 단위로 올림한 값입니다(단일 시드 0.06 dB, 2시드 이상 0.04 dB). RR 세 지표가 모두 좋아져도 문턱 미만이면 **부분 개선**으로 표기하고 확인된 결과에 "잡음 수준"을 적습니다.
- 단일 시드는 해당 시드의 값을 사용합니다. 여러 시드는 같은 조건 대조군과 짝지은 전체 시드의 지표를 각각 산술평균한 뒤 후보 − 대조군 차이로 판정합니다.
- 여러 시드 중 하나만 통과했다고 전체를 개선으로 표기하지 않습니다. 평균이 RR 판정을 통과하면 개선이며, 과반 시드의 PSNR 개선을 추가로 요구하지 않습니다.
- 사전에 정한 비교 시드를 일부 제외하거나 유리한 시드만 고르지 않습니다. 예정된 평가가 끝나지 않았다면 판단 보류로 표기합니다.
- 시드 수와 시드 ID, 시드별 결과, 여러 시드의 평균을 함께 보고합니다. 단일 시드의 개선을 여러 시드에서 재현된 결과로 해석하지 않습니다.

## 판정 이름

| 판정 | 조건 |
|---|---|
| 개선 | 단일 시드 값 또는 여러 시드 평균의 RR PSNR·SAM·ERGAS가 모두 좋아지고 PSNR 이득이 잡음 문턱 이상 |
| 부분 개선 | RR PSNR·SAM·ERGAS 중 일부만 개선, 또는 세 지표가 모두 좋아졌지만 PSNR 이득이 잡음 문턱 미만(잡음 수준) |
| 개선 없음 | RR PSNR·SAM·ERGAS 모두 개선 없음 |
| 판단 보류 | 같은 조건 대조군과 짝지은 RR test 20장 평가가 끝나지 않음 |
| 비교 기준·성능 비교 아님 | 판정 대상 아님 |

## 채택과 보고

- 개선 표기와 기준 모델 교체를 구분합니다. 기준 모델 교체에는 3시드 이상에서 평균 판정이 "개선"이어야 합니다. 단일 시드 결과만으로 기준 모델을 교체하지 않습니다.
- 기준 모델 교체를 제안하는 보고서에는 현재 기준 모델과 같은 시드·같은 고정 장면의 FR 결과 비교 이미지를 함께 싣습니다. FR에는 정답이 없으므로 정량 판정이 아니라 색 번짐·과한 세부 같은 흔적을 확인하는 정성 자료입니다.
- 기준 모델 교체 판단은 판정한 센서(현재 QB)에 한정해 기록합니다. 다른 센서 확인은 권장 사항이며, 하지 않았다면 그 사실을 보고서에 적습니다.
- 기준 모델이 바뀌면 이후 새 실험의 대조군은 새 기준 모델입니다. 이전 실험의 판정과 대조군은 바꾸지 않습니다.
- 후보와 가중치는 validation으로 고르고, test로 다시 고르지 않습니다. 어떤 후보도 자동 승격하지 않습니다.
- 새 FR 지표는 성능 46번의 정답 순위 검사(정답이 가장 좋은 점수를 받는지)를 통과해야 판정에 넣을 수 있습니다.
- 다른 센서·배율에 적용할 때는 잡음 문턱을 그 조건의 시드 편차로 다시 정합니다.

## 보조 판정 삭제 (v2.3 → v2.4)

2026-11-04 사용자 결정으로 RR2·FR_WALD·FR 관측 일치의 보조 판정 3개를 판정 기준에서 삭제했습니다. 판정은 RR 지표(잡음 문턱 포함)만으로 하고, FR QNR·Dλ·Ds는 참고로 보고합니다. 잡음 문턱은 유지합니다.

- 47번 측정값의 후보 96개는 개선 5 → 34개, 부분 개선 58 → 29개, 개선 없음 33개(그대로)가 됐습니다. 바뀐 29개는 모두 RR 판정을 통과했지만 보조 판정(대부분 RR2)에 미달했던 후보입니다.
- 실험 표에서는 6·10·15·17·18·19·20·23·27·33·38·40·42·43·44·48·63번이 개선으로 바뀌었습니다. 27번은 보조 판정 자료가 없어 판단 보류였지만, 같은 조건 대조군 E0 대비 RR 세 지표가 모두 좋아졌습니다(+0.480 dB).
- 보조 판정 자료가 없어 판단 보류였던 31번은 RR 세 지표가 모두 나빠 개선 없음, 37번은 RR 이득이 잡음 문턱 미만이라 부분 개선입니다.
- 여러 센서를 평가한 실험은 센서별 판정을 확인된 결과에 적고, 실험 전체 판정은 지금까지처럼 평가한 센서가 모두 개선일 때만 개선으로 둡니다. 65번 GF2(3시드)·67번 WV2 전이·71번 WV2 전이는 센서별로 개선이 됐지만, 다른 센서가 개선되지 않아 실험 전체 판정은 그대로입니다.
- 이미 개선이던 실험은 RR 판정을 통과했으므로 그대로이고, 개선 없음도 그대로입니다. 기준 모델 C2MS의 채택 근거(53·54번 3시드 개선)도 바뀌지 않습니다.
- 실험 표·catalog의 확인된 결과에서 보조 판정 항목의 통과·미달 기록을 지웠습니다. 실험 주제가 그 값 자체인 분석(50번 W2 세기와 RR2, 66번 관측 오차 분해, 69번 관측 일치 손실, 72번 주파수 분해)의 측정 내용은 실험 결과로 남겼습니다.

## 기존 실험 표에 반영하는 방법

- [현재 표 판정](../experiments/performance/47_ground_truth_criteria_reevaluation/results/summary_v2_4.json)은 후보 96개의 동일한 시드 평균 RR 차이에 v2.4를 적용한 결과입니다. 개선 34개·부분 개선 29개·개선 없음 33개입니다. v2.3·v2.2 집계는 [summary_v2_3.json](../experiments/performance/47_ground_truth_criteria_reevaluation/results/summary_v2_3.json)·[summary_v2_2.json](../experiments/performance/47_ground_truth_criteria_reevaluation/results/summary_v2_2.json)에 보존합니다.
- 여러 후보가 있는 실험 표의 개선 여부는 후보별 판정 중 가장 높은 단계로 요약하고, 확인된 결과 열에 해당 후보를 적습니다. 다른 후보까지 개선됐다는 뜻이나 test로 최종 모델을 다시 선택한다는 뜻이 아닙니다.
- QB 재평가 판정은 다른 센서·배율로 확대하지 않습니다. 33·38번은 합친 3시드 평균 판정을 두 표에 동일하게 반영합니다.
- 같은 조건 대조군과 짝지은 RR test 20장 평가가 없는 성능 비교는 판단 보류로 표시하고 부족한 근거를 적습니다. 구조 검사·관측 분석은 성능 비교 아님, 원본 기준선은 비교 기준으로 유지합니다.
- 개별 실험의 원래 보고서와 47번의 v2 표는 작성 당시 기록입니다. 판정이 바뀐 보고서에는 첫머리 요약 표 아래에 v2.4 재집계 결과를 한 줄로 덧붙입니다. 현재 판정은 연구별 표와 현재 표 판정 JSON을 함께 확인합니다.
- 판정 재계산은 `python SSA-MRN/experiments/performance/47_ground_truth_criteria_reevaluation/prepare.py v2.4`로 재현합니다. 이 명령은 보존된 `results/summary.json`을 읽고 `results/summary_v2_4.json`만 생성합니다(`v2.3`·`v2.2`를 주면 해당 집계를 같은 값으로 다시 만듭니다).

## QB RR2 고정 대조값 (2026-10-27)

보관된 53번 C2MS의 RR2가 같은 레시피로 다시 학습한 모델들보다 높게 나와, 2026-10-27부터 v2.3의 QB RR2 보조 판정은 [성능 57번](../experiments/performance/57_c2ms_training_conditions/README.md) 재학습 C2MS seed 42의 RR2(PSNR 39.1148 dB, SAM 4.2410°)를 고정 대조값으로 썼습니다(58번부터 소급). v2.4에서 RR2 판정을 삭제해 더 이상 쓰지 않습니다.

## 허용폭 근거 (v2 → v2.1)

v2.1은 보조 판정 허용폭을 각 시험의 3시드 대조군 시드 표준편차 중앙값에 맞췄습니다(RR2 ΔPSNR ≥ −0.05 dB·ΔSAM ≤ +0.06°, FR_WALD ΔPSNR ≥ −0.07 dB·ΔSAM ≤ +0.04°, FR 관측 RMSE 비율 ≤ 1.10). v2.1을 47번 후보에 적용하면 "개선"이 6개에서 10개로 늘었습니다.

## 시드 판정 변경 (v2.1 → v2.2)

단일 시드도 모든 판정 항목을 통과하면 개선으로 표기한다는 점을 명시했습니다. 여러 시드는 전체 시드 평균으로 판정하며, 기존의 과반 시드 PSNR 개선 조건은 제거했습니다.

## 잡음 문턱 추가 (v2.2 → v2.3)

v2.2에서는 RR ΔPSNR이 0보다 크기만 하면 주 판정을 통과해, +0.02 dB처럼 시드 편차보다 작은 차이도 "개선"으로 표기됐습니다. v2.3은 시드 수에 맞춘 잡음 문턱을 주 판정에 더했습니다. 47번 측정값에 적용하면 단일 시드 "개선" 5개(17 S1 +0.019 dB·S2 +0.056 dB, 44 F2 +0.021 dB, SSAI 1 A1 +0.055 dB, SSAI 12 B3 +0.050 dB)가 부분 개선으로 바뀌고, 개선은 28 G5·29 F01·29 F11·21 E6·26 ema의 5개가 남았습니다. 잡음 문턱은 v2.4에서도 유지합니다.
