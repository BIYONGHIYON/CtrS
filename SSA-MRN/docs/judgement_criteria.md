# 성능 개선 판정 기준 (v2.3)

모든 연구 분야의 현재 실험 표에 이 기준을 적용합니다. 기존 실험은 [성능 47번](../experiments/performance/47_ground_truth_criteria_reevaluation/README.md)의 보존된 측정값으로 [현재 표 판정](../experiments/performance/47_ground_truth_criteria_reevaluation/results/summary_v2_3.json)을 다시 계산합니다. 47번에서 측정 전에 고정했던 v2 판정과 원본 수치는 보존하며, 현재 표의 v2.3 판정과 구분합니다. 새 학습이나 추론으로 결과를 바꾸지 않습니다.

## 왜 바꿨나

- [성능 46번](../experiments/performance/46_fr_spatial_index_validity/README.md): QB에서 FR Ds(Toolbox 1.0·원 논문 방식 모두)가 정답을 모델 출력보다 나쁘게 채점했습니다. 이 지표로 거부권을 행사하면 실제로 좋아진 결과를 탈락시킬 수 있습니다.
- [성능 47번](../experiments/performance/47_ground_truth_criteria_reevaluation/README.md): 후보 96개에서 ΔQNR과 정답 기반 FR 장면 시험(FR_WALD)의 ΔPSNR은 순위 상관 −0.10으로 거의 무관했습니다.
- [성능 51번](../experiments/performance/51_fr_detail_index_validity/README.md): PAN 유사도로 FR 세부를 재는 지표 4개도 정답을 모델보다 나쁘게 채점했습니다(0/20장, 순위 상관 −0.62에서 −0.77).

그래서 판정은 정답이 있는 시험으로만 하고, QNR·Dλ·Ds는 문헌 비교용으로만 보고합니다.

## 판정 항목

| 구분 | 시험 | 통과 조건 |
|---|---|---|
| 주 판정 | RR: PanCollection RR test 20장 | 같은 조건 대조군 대비 시드 평균 ΔPSNR ≥ 잡음 문턱(단일 시드 0.06 dB, 2시드 이상 0.04 dB), ΔSAM < 0, ΔERGAS < 0 |
| 보조 1 | RR2: RR 장면을 같은 Wald 열화로 한 번 더 1/4 축소, 정답 = RR MS | 시드 평균 ΔPSNR ≥ −0.05 dB, ΔSAM ≤ +0.06° |
| 보조 2 | FR_WALD: FR 장면을 같은 열화로 1/4 축소, 정답 = 실제 FR MS | 시드 평균 ΔPSNR ≥ −0.07 dB, ΔSAM ≤ +0.04° |
| 보조 3 | FR_OBS: FR 출력을 MS 관측 연산자로 줄였을 때 실제 FR MS와의 내부 RMSE(DN, 가장자리 5화소 제외) | 대조군 대비 1.10배 이하 |
| 참고 | FR QNR·Dλ·Ds, RR SCC·Q2n, RR2·FR_WALD ERGAS | 판정에 쓰지 않고 보고만 함 |

열화·보간·관측 연산은 [common/evaluation_protocol.py](../common/evaluation_protocol.py)를 사용합니다. [성능 47번 run.py](../experiments/performance/47_ground_truth_criteria_reevaluation/run.py)의 `judge`는 보존된 v2 재평가용입니다. 새 실험은 이 문서의 평균 판정 방식과 허용폭을 따릅니다.

## QB RR2 고정 대조값 (2026-10-27)

보관된 53번 C2MS(QB 기준 모델의 원래 실행)의 RR2가 같은 레시피로 다시 학습한 모델들보다 높게 나왔습니다. 57번에서 같은 시드로 C2MS를 다시 학습했을 때 53번 대비 RR2가 −0.306 dB였고, 이후 QB에서 새로 학습한 후보(58·63·64·65번)도 바꾼 내용과 관계없이 53번보다 RR2가 0.18-0.47 dB 낮았습니다. 학습·validation 캐시의 해시는 53번과 같으므로, 53번 seed 42·43의 RR2(39.42 dB 안팎)가 이례적으로 높은 것으로 봅니다. seed 44는 39.12 dB로 다른 실행과 비슷합니다.

2026-10-27 사용자 결정에 따라 QB의 보조 1(RR2) 판정은 다음과 같이 합니다.

| 항목 | 규칙 |
|---|---|
| RR2 대조값 | [성능 57번](../experiments/performance/57_c2ms_training_conditions/README.md)의 재학습 C2MS seed 42 RR2 하나로 고정: PSNR 39.1148 dB, SAM 4.2410° |
| 후보 값 | 단일 시드는 그 시드의 RR2, 여러 시드는 시드 평균 RR2 |
| 허용폭 | 그대로: ΔPSNR ≥ −0.05 dB, ΔSAM ≤ +0.06° |
| 나머지 판정 | 주 판정(RR), 보조 2(FR_WALD), 보조 3(FR 관측 일치)은 지금처럼 같은 시드의 53번 C2MS와 짝지어 판정 |
| 적용 범위 | 58번부터 소급(58·63·64·65번과 이후 QB 실험). 그 이전 실험과 다른 센서는 바꾸지 않음 |

같은 학습 파이프라인으로 C2MS 대조군을 새로 학습하게 되면 이 규칙을 다시 검토합니다.

## 시드 수와 집계

- 단일 시드도 주 판정과 보조 판정 3개를 모두 통과하면 **개선**으로 표기합니다. 개선 표기에 3시드 이상을 요구하지 않습니다.
- RR ΔPSNR은 잡음 문턱 이상이어야 합니다. 문턱은 성능 43번 C0의 RR 시드 표준편차(0.056 dB)를 시드 수의 제곱근으로 나눠 0.01 dB 단위로 올림한 값입니다(단일 시드 0.06 dB, 2시드 이상 0.04 dB). 다른 항목을 모두 통과해도 문턱 미만이면 **부분 개선**으로 표기하고 확인된 결과에 "잡음 수준"을 적습니다.
- 단일 시드는 해당 시드의 값을 사용합니다. 여러 시드는 같은 조건 대조군과 짝지은 전체 시드의 지표를 각각 산술평균한 뒤 후보 − 대조군 차이로 판정합니다. FR_OBS는 후보의 시드 평균 RMSE를 대조군의 시드 평균 RMSE로 나눈 비율입니다.
- 여러 시드 중 하나만 통과했다고 전체를 개선으로 표기하지 않습니다. 평균이 모든 항목을 통과하면 개선이며, 과반 시드의 PSNR 개선을 추가로 요구하지 않습니다.
- 사전에 정한 비교 시드를 일부 제외하거나 유리한 시드만 고르지 않습니다. 예정된 평가가 끝나지 않았다면 판단 보류로 표기합니다.
- 시드 수와 시드 ID, 시드별 결과, 여러 시드의 평균을 함께 보고합니다. 단일 시드의 개선을 여러 시드에서 재현된 결과로 해석하지 않습니다.

## 판정 이름

| 판정 | 조건 |
|---|---|
| 개선 | 단일 시드 값 또는 여러 시드 평균이 주 판정(잡음 문턱 포함)과 보조 판정 3개를 모두 통과 |
| 부분 개선 | 주 판정은 통과했지만 보조 판정 중 하나 이상 미달, PSNR·SAM·ERGAS 중 일부만 개선, 또는 모든 항목을 통과했지만 RR 이득이 잡음 문턱 미만 |
| 개선 없음 | PSNR·SAM·ERGAS 모두 개선 없음 |
| 판단 보류 | 최종 RR·FR 평가가 끝나지 않음 |
| 비교 기준·성능 비교 아님 | 판정 대상 아님 |

보조 판정에서 미달했다면 확인된 결과에 어느 항목인지(예: "RR2 SAM +0.10°")를 적습니다.

## 채택과 보고

- 개선 표기와 기준 모델 교체를 구분합니다. 기준 모델 교체에는 3시드 이상에서 평균 판정이 "개선"이어야 합니다. 단일 시드 결과만으로 기준 모델을 교체하지 않습니다.
- 기준 모델 교체를 제안하는 보고서에는 현재 기준 모델과 같은 시드·같은 고정 장면의 FR 결과 비교와 RR2 오차 비교 이미지를 함께 싣습니다. FR에는 정답이 없으므로 정량 판정이 아니라 색 번짐·과한 세부 같은 흔적을 확인하는 정성 자료입니다.
- 기준 모델 교체 판단은 판정한 센서(현재 QB)에 한정해 기록합니다. 다른 센서 확인은 권장 사항이며, 하지 않았다면 그 사실을 보고서에 적습니다.
- 기준 모델이 바뀌면 이후 새 실험의 대조군은 새 기준 모델입니다. 이전 실험의 판정과 대조군은 바꾸지 않습니다.
- 후보와 가중치는 validation으로 고르고, test로 다시 고르지 않습니다. 어떤 후보도 자동 승격하지 않습니다.
- 새 FR 지표는 성능 46번의 정답 순위 검사(정답이 가장 좋은 점수를 받는지)를 통과해야 판정에 넣을 수 있습니다.
- 다른 센서·배율에 적용할 때는 같은 열화를 그 센서의 MTF로 바꾸고, 허용폭도 그 조건의 시드 편차로 다시 정합니다.

## 허용폭 근거 (v2 → v2.1)

v2는 RR의 시드 표준편차(PSNR 0.056 dB, SAM 0.021°)로 보조 판정 허용폭을 정했습니다. 성능 47번에서 각 시험의 시드 편차를 직접 재 보니, RR2와 FR_WALD의 SAM 편차가 그보다 컸습니다. v2.1은 각 시험의 허용폭을 그 시험 자체의 잡음 크기에 맞춥니다.

| 시험 | 3시드 대조군 4개(성능 6, 33·38, 39, 43)의 시드 표준편차 | 중앙값 | v2.1 허용폭 |
|---|---|---:|---:|
| RR2 PSNR | 0.084 · 0.051 · 0.025 · 0.037 dB | 0.044 | −0.05 dB |
| RR2 SAM | 0.035 · 0.096 · 0.077 · 0.037° | 0.057 | +0.06° |
| FR_WALD PSNR | 0.070 · 0.026 · 0.089 · 0.052 dB | 0.061 | −0.07 dB |
| FR_WALD SAM | 0.035 · 0.046 · 0.030 · 0.019° | 0.032 | +0.04° |

허용폭은 중앙값을 0.01 단위로 올림한 값입니다. 47번 결과를 본 뒤 정한 값이므로 47번 판정에는 소급 적용하지 않습니다. 참고로 v2.1을 47번 후보에 적용하면 "개선"이 6개에서 10개(44 F2, 17 S1, SSAI 1 A1, SSAI 12 B3 추가, 모두 단일 시드)로 늘고, 43 C2·C3·29 W2·33·38 N1의 RR2 미달은 그대로입니다.

## 시드 판정 변경 (v2.1 → v2.2)

단일 시드도 모든 판정 항목을 통과하면 개선으로 표기한다는 점을 명시했습니다. 여러 시드는 전체 시드 평균으로 판정하며, 기존의 과반 시드 PSNR 개선 조건은 제거했습니다. 보조 판정 허용폭과 기준 모델 교체의 3시드 조건은 유지합니다. 47번의 원래 v2 판정은 보존하고 현재 실험 표에는 같은 측정값으로 계산한 v2.2 판정을 적용합니다.

## 잡음 문턱 추가 (v2.2 → v2.3)

v2.2에서는 RR ΔPSNR이 0보다 크기만 하면 주 판정을 통과해, +0.02 dB처럼 시드 편차보다 작은 차이도 "개선"으로 표기됐습니다. v2.3은 시드 수에 맞춘 잡음 문턱을 주 판정에 더했습니다. 47번 측정값에 적용하면 단일 시드 "개선" 5개(17 S1 +0.019 dB·S2 +0.056 dB, 44 F2 +0.021 dB, SSAI 1 A1 +0.055 dB, SSAI 12 B3 +0.050 dB)가 부분 개선으로 바뀌고, 개선은 28 G5·29 F01·29 F11·21 E6·26 ema의 5개가 남습니다. 48번 이후 실험의 판정은 바뀌지 않습니다(49번 F1은 3시드 평균 +0.194 dB).

## 기존 실험 표에 반영하는 방법

- [현재 표 판정](../experiments/performance/47_ground_truth_criteria_reevaluation/results/summary_v2_3.json)은 후보 96개의 동일한 시드 평균 차이와 관측 오차 비율에 v2.3을 적용한 결과입니다. 개선 5개·부분 개선 58개·개선 없음 33개이며, 개선 5개는 모두 단일 시드입니다. v2.2 집계는 [summary_v2_2.json](../experiments/performance/47_ground_truth_criteria_reevaluation/results/summary_v2_2.json)에 보존합니다.
- 여러 후보가 있는 실험 표의 개선 여부는 후보별 판정 중 가장 높은 단계로 요약하고, 확인된 결과 열에 해당 후보를 적습니다. 다른 후보까지 개선됐다는 뜻이나 test로 최종 모델을 다시 선택한다는 뜻이 아닙니다.
- QB 재평가 판정은 다른 센서·배율로 확대하지 않습니다. 33·38번은 합친 3시드 평균 판정을 두 표에 동일하게 반영합니다.
- 평가 범위에서 제외됐거나 보조 판정이 없는 성능 비교는 판단 보류로 표시하고 부족한 근거를 적습니다. 구조 검사·관측 분석은 성능 비교 아님, 원본 기준선은 비교 기준으로 유지합니다.
- 개별 실험의 원래 보고서와 47번의 v2 표는 작성 당시 기록입니다. 현재 판정은 연구별 표와 현재 표 판정 JSON을 함께 확인합니다.
- 판정 재계산은 `python SSA-MRN/experiments/performance/47_ground_truth_criteria_reevaluation/prepare.py v2.3`으로 재현합니다. 이 명령은 보존된 `results/summary.json`을 읽고 `results/summary_v2_3.json`만 생성합니다(`v2.2`를 주면 `summary_v2_2.json`을 다시 만듭니다).
