# 짧은 예비 실험

6가지 개선 후보, 공통 10에폭 기준 설정과 서버 실행 방법은 [6단계 예비 실험 환경](six_stage_pilot.md)에 정리했습니다.

전체 393개 학습·45개 검증 장면, 256×256·204밴드를 유지하고 에폭을 줄입니다. [공통 기준 설정](../../configs/pilot/00_baseline10.json)은 기존 RGB07과 같은 구조를 사용합니다. 최근 에폭당 약 184초에서 10에폭 약 31분을 예상하며 실제 run 시작 후 다시 측정합니다.

후보와 기준 모델을 같은 예산에서 비교하고, 유망 후보만 20~30에폭으로 재확인합니다. test75는 최종 후보를 고른 뒤 평가합니다.
