# PAN–MS 성능 개선 실험 계획

[현재 연구](../README.md)

## 1. 통제된 기준선

K6를 우선 기준으로 QB/GF2/WV3의 학습·검증·RR/FR 분할, 정규화, 제공 LMS를 확인합니다. 같은 GPU·백엔드에서 기준선부터 실행합니다. K4/K6를 비교할 경우 장치·학습량·분할·시드를 맞춥니다. 과거 서로 다른 장치 결과로 K의 인과 효과를 주장하지 않습니다.

## 2. 작은 단일 변경 실험

검증셋에서 분광 손실, 공간 경계 손실, attention 연산 검증을 각각 독립 후보로 시험합니다. 이는 아직 채택하거나 구현한 개선안이 아닙니다. 개인 RGB–HSI의 성능 이득이 PAN–MS에 재현된다고 가정하지 않습니다. 특히 area 평균 보정은 센서/MTF 축소와 다르므로 그대로 넣지 않습니다.

## 3. 전체 평가

검증에서 선택한 후보와 같은 학습량의 대조군을 비교합니다. 센서별 RR/FR 전체 지표, 장면별 수치, 사전 선택 5장면, 학습·검증 곡선, 코드·가중치 해시를 함께 기록합니다. FR 무참조 지표와 RR GT 지표를 구분합니다. 테스트 반복 사용 이력을 밝힙니다.

이 문서는 실험 설계이며 새 학습을 실행하지 않았습니다. 데이터 경로·GPU 사용 가능 여부를 확인한 뒤 명시적인 실행 요청으로 시작합니다.
