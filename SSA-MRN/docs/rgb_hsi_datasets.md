# RGB 유도 HSI 공간 초해상도용 데이터셋 감사

2026-10-01에 외장 드라이브의 SSA-MRN Data/RGB-HSI 폴더를 **읽기 전용**으로 조사했다. 크기는 실제 파일의 가로×세로 픽셀이며, 물리적 픽셀 피치나 두 카메라의 동일한 시야를 뜻하지 않는다. 공개 규모와 로컬에서 확인한 파일 수를 구분한다. 원본 데이터는 수정하지 않았고 Git에도 넣지 않는다.

## 핵심 결론

- **실제 고해상도 RGB + 저해상도 HSI** 연구에는 BUSIFusion과 PCB-Vision이 가장 직접적이다. 두 자료 모두 서로 다른 카메라의 공통 시야와 정합을 확인해야 하며, 고해상도 HSI 정답은 없다.
- **합성 4배 축소 정량 실험**에는 Agro-HSR(1,322쌍·31밴드)과 LIB-HSI(513쌍·204밴드)가 유용하다. 배포 RGB와 HSI가 모두 512×512이므로 이를 실제 센서 공간 초해상도 성능으로 주장하지 않는다.
- HSI Road의 로컬 배포본은 **RGB와 25밴드 NIR**로 구성된다. 이전 문서의 가시광 16밴드 HSI 설명은 이 배포본에 해당하지 않는다. 원본 NIR의 높이는 192픽셀이므로 256×256 완전 패치를 뽑을 수 없다.
- NTIRE2022에는 **HSI만 있고 RGB 파일이 없다.** 학습 파일 하나는 잘린 HDF5다. HSIFoodIngr-64는 **지정 경로에 없다.** 둘 다 확보된 실제 RGB–HSI 쌍 수에 더하지 않는다.

¹ **고해상도 HSI 정답 격자**에서 겹치지 않는 256×256 완전 패치만 세었다. 장면별 개수는 ⌊가로/256⌋ × ⌊세로/256⌋이고 남는 가장자리는 버린다. 4배 합성 열화에서는 각 256×256 정답에서 64×64 저해상도 HSI를 만든다. 표의 값은 **기하학적 후보 상한**이며 RGB와 HSI의 정합, 공통 시야, 배경 마스크를 적용한 실제 학습 가능 쌍 수가 아니다. PCB 16개 장면은 원본 HSI의 한 변이 256보다 작다. 겹침·회전·증강은 패치 수를 늘려도 독립 장면 수를 늘리지 않는다.

## 로컬 감사에서 확인한 예외와 수량 근거

- **PCB:** 번호 1–53의 RGB JPEG와 HSI ENVI 바이너리가 대응한다. 53개 HSI 모두 헤더로 계산한 바이트 수와 실제 크기가 일치한다. 패치 139개는 장면별 크기를 이용해 합산한 값이며, RGB와 HSI의 실제 공통 시야를 적용하면 감소할 수 있다.
- **BUSIFusion:** 번호별로 HSI 헤더·RAW, 보조 PNG, RGB/RYB JPEG·DNG의 7종 파일이 142세트 있다. HSI는 ENVI BIL uint16이며 142개 RAW 바이트 수가 헤더와 맞는다. [공식 설명](https://github.com/CPREgroup/Real-Spec-RGB-Fusion#real-world-dataset)의 카메라 5472×7296 해상도와 달리 **로컬 배포 RGB JPEG는 전부 4000×3000**이다. DNG 격자는 이번 검사에서 확정하지 않았다. 보조 파일 133.png만 645×645이므로 고정 512 전처리의 예외다.
- **Agro-HSR:** 학습 1,040쌍과 시험 282쌍의 번호가 RGB JPEG와 HSI MAT에서 모두 일치한다. 모든 HDF5 cube의 저장 shape는 31×512×512, 자료형은 float64다. 논문의 790 **개체**와 1,322 **영상 쌍**은 다른 표본 수다. 시험 282장은 141개체의 양면 촬영이다.
- **LIB-HSI:** RGB·라벨 PNG와 HSI HDR/DAT가 393/45/75개로 모두 이름이 맞고, 513개 DAT의 바이트 수가 헤더와 일치한다. HSI는 ENVI BIL float32다. 배포 readme의 **영상당 9개 256 패치**는 겹치는 위치를 선택한 수이고, 이 표의 비중첩 4개와 계산법이 다르다. 회전한 36개도 독립 장면 36개가 아니다.
- **HSI Road:** RGB와 NIR TIFF가 각각 3,799개로 번호가 모두 맞는다. 전 파일의 shape는 RGB 3×704×1280, NIR 25×192×384이고 NIR은 uint8이다. all.txt 3,799개 중 train.txt 1,848개, valid.txt 1,241개가 있으며 중복이 없다. 나머지 **710개를 임의로 공식 시험 세트라 부르지 않는다.** 연속 주행 프레임을 독립 경로로 세지도 않는다.
- **NTIRE2022:** Train_spectral 900개, Valid_spectral 45개만 있다. [논문](https://openaccess.thecvf.com/content/CVPR2022W/NTIRE/papers/Arad_NTIRE_2022_Spectral_Recovery_Challenge_and_Data_Set_CVPRW_2022_paper.pdf)의 전체 1,000장(900/50/50)과 구분한다. **Train_spectral/ARAD_1K_0314.mat는 잘린 HDF5 오류**로 열리지 않는다. 다른 944개는 메타데이터를 열 수 있음까지만 확인했으며 전 픽셀·체크섬 무결성을 증명한 것은 아니다.
- **HSIFoodIngr-64:** [배포 페이지](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/E7WDNQ)의 3,389쌍은 공개 규모다. 지정 경로에는 해당 폴더·압축 파일이 없어 로컬 사용 가능 수와 패치를 확정하지 않는다.

## 256×256 입력과 평가 프로토콜

현재 PAN–MS 재현의 **256×256은 평가 영상 크기/패치 선택**이다. [모델 코드](../src/ssamrn/models/ssa_mrn.py)는 공간 크기가 4의 배수인지 검사하지만, RGB 3채널과 HSI 25/31/204/224채널을 그대로 받는 RGB–HSI 모델은 아직 아니다. 입력부·출력부·메모리 사용량을 따로 구현하고 확인해야 한다. 밴드 수와 파장 범위가 다른 데이터셋을 채널 번호만 맞춰 한 모델에 무분별하게 합치지 않는다.

1. **장면 단위로 먼저 분할:** PCB 번호, 고구마 개체, 건물/인접 촬영 위치, 주행 구간을 분할한 뒤 패치를 추출한다. 원래 배포 시험 세트를 학습에 섞지 않는다. 패치 평균을 독립 표본 평균처럼 쓰지 않는다.
2. **합성 축소 정량 실험:** HSI에 공개된 동일한 블러·4배 축소 규칙을 적용해 256×256 HSI를 정답, 64×64 HSI를 입력으로 둔다. 정합된 실제 RGB와 HSI에서 만든 합성 RGB 가이드는 별도 결과로 표시한다. Nearest·Bicubic·HSI 단독 모델·RGB 가이드 모델을 같은 분할에서 비교한다.
3. **합성 지표:** PSNR(고정 데이터 범위와 밴드 집계법 명시), 밴드별 SSIM 평균, SAM(도), ERGAS(스케일 4), LR 재투영 오차를 보고한다. DN·반사율·uint8의 범위와 배경/포화 마스크를 확인하고 정규화 통계는 학습 장면에서만 구한다. 장면/개체별 수치와 그 단위의 변동·신뢰구간을 제시한다. 데이터셋 간 다른 밴드·파장·열화 조건의 PSNR을 직접 순위로 해석하지 않는다.
4. **실제 센서 쌍 실험:** BUSI·PCB, 조건을 만족한 Road의 공통 시야, 수동/자동 랜드마크, 홀드아웃 정합 오차와 유효영역을 먼저 확인한다. 출력 HSI를 고정된 열화·정합 모델로 LR 격자에 다시 투영해 관측 HSI와 비교하고 스펙트럼·경계·여러 밴드의 시각화와 실패 사례를 보고한다. **실제 HR HSI 정답이 없으므로 PSNR/SSIM/SAM을 실제 HR 성능 지표로 쓰지 않는다.** RGB와 NIR/HSI의 픽셀값을 같은 물리량으로 직접 비교하지 않는다.

이 표의 패치 수는 파일 크기에서 계산한 **후보**다. 실제 학습 가능 수는 장면별 정합과 공통 시야 마스크가 생긴 뒤 다시 세어야 한다.
