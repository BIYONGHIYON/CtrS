# PCB-Vision 기반 RGB 유도 HSI 초해상도: 데이터 감사와 첫 기준선

## 연구 질문과 확인된 범위

목표는 **실제 고해상도 RGB + 저해상도 HSI**에서 더 촘촘한 공간 격자의 HSI를 추정하는 것이다. 기존 PAN–MS SSA-MRN의 공개 코드 기반 K=4 재현과 평가 결과는 별도 기준으로 보존한다. RGB 3채널, HSI 224채널, 비정수·장면별 해상도 비율, 서로 다른 시야와 광학 특성 때문에 기존 체크포인트를 그대로 적용하거나 입력 PAN만 RGB로 바꾸는 것으로는 검증된 확장이 되지 않는다. 원본 SSA-MRN은 밴드별 처리 구조이므로 224밴드에서 메모리·시간을 먼저 측정해야 한다.

PCB-Vision 논문과 [공식 데이터 기록](https://rodare.hzdr.de/record/2704)에 따르면 카메라는 Teledyne Dalsa C4020과 Specim FX10이고, 53개의 서로 다른 PCB를 각각 촬영했다. HSI는 224밴드 반사율 데이터로 설명된다. 이 데이터셋은 분할용으로 제공되며, **실제 고해상도 HSI 정답과 픽셀 정렬된 RGB–HSI 변환은 제공한다고 확인되지 않았다.** 따라서 아래의 두 실험을 분리한다.

1. **합성 축소 정량 실험:** 기존 HSI를 가상 HR 정답으로 놓고 알려진 4배 열화로 LR HSI를 만든다. RGB 가이드를 쓰는 모델 실험은 RGB↔HSI 정합이 확인된 장면에서만 수행하며, 정합 자체의 오차를 함께 보고한다. RGB 없이 HSI에서 유도한 3밴드 가이드는 *합성 가이드*라고 별도 표기한다.
2. **실제 센서 쌍 실험:** 촬영된 RGB와 HSI를 정합·공통 시야 마스킹 후 사용한다. HR HSI 정답이 없으므로 PSNR/SAM을 실제 성능으로 주장하지 않는다. LR 재투영 일치, 스펙트럼 보존, RGB 경계와의 구조적 일치, 시각화와 실패 사례를 보고한다. 서로 다른 센서의 RGB 색과 HSI 반사율을 직접 픽셀별 동일값으로 두지 않는다.

## 파일 감사 (2026-09-29)

원본 경로: `/Volumes/T7 Shield/윤지/병현/SSA-MRN Data/RGB-HSI/PCBDataset`. `RGB/{번호}.jpg`와 `HSI/pcb{번호}/pcb{번호}` 및 `.hdr` 53쌍이 모두 있다. 53개 ENVI 바이너리의 헤더상 크기와 실제 바이트 수가 일치한다. 6개(1,2,3,4,5,7)는 BSQ, 47개는 BIP이다. 51개 헤더는 `bands=224`인데 파장 목록에 **448개**를 기재하고, 46·47번은 파장 목록이 없다. 따라서 채널별 nm 대응은 미확정이다. 논문에 적힌 약 400–1000 nm 범위를 224개 배열 인덱스에 선형 배분하지 않는다. 여기의 HSI 미리보기는 헤더 기본 밴드 89/64/28을 **인덱스**로 사용했으며 진색 표준화가 아니다.

HSI 반사율 설명과 달리 표본에는 음수와 1 초과 값이 있다. 원본을 조용히 `[0,1]`로 자르지 않는다. 센서/헤더의 처리 경위를 확인하고, 비정상값 비율·밴드별 분포를 전 장면에서 감사한 뒤 동일한 고정 규칙을 학습·검증·테스트에 적용한다. 배경과 포화·비유한값을 마스크로 분리하고, 정규화 통계는 학습 PCB에서만 추정한다.

## 재현 가능한 분할과 전처리 계획

`scripts/make_pcb_split.py`는 1~53번 쌍을 확인하고 시드 42로 `configs/pcb_split_seed42.json`을 만든다. 현재 **학습 33, 검증 10, 테스트 10 PCB**다. 논문의 분할은 분할 *작업*을 위한 33/9/11이며, 여기의 초해상도 분할과 동일하다고 주장하지 않는다. 패치는 분할 후에 각 PCB 내부에서 추출한다. 같은 PCB의 RGB·HSI·패치·증강본은 항상 같은 집합에 속한다. 패치가 수천 장이어도 독립 장면 수는 53개다.

전처리 순서: (1) ENVI 메타데이터·값·마스크 감사, (2) 장면별 회전·공통 시야와 수동 기준점 확인, (3) 검증 가능한 기하 변환 및 유효영역 마스크 저장, (4) HSI 격자 기준으로 RGB 변환하되 보간·변환과 광도 처리를 기록, (5) 학습 PCB에 한해서만 패치와 증강 생성. 실제 스케일은 단순히 이미지 너비 비율로 정의하지 않는다. 먼저 유효영역에서 대응점 간 스케일과 왜곡을 추정한다. 정합 코드가 확정되기 전에는 가이드 모델 학습을 보류한다.

## 기준 모델과 평가

- 첫 합성 기준: **Nearest, Bicubic** (HSI만 사용). 열화 커널, 4배 비율, 경계 처리, PSNR peak와 마스크를 고정한다.
- 다음 합성 기준: RGB 없는 경량 HSI SR 모델과 동일 용량의 RGB 가이드 모델; 가능하면 원 SSA-MRN 구조를 3채널 RGB 인코더 + 224채널 HSI 특징 추출/그룹화로 확장한 변형. 전체 224밴드 출력·SAM 보조 손실 등은 계산량을 측정한 뒤 비교한다. 가이드 제거 실험으로 RGB의 기여를 분리한다.
- 합성 정량: PCB별 PSNR, SAM, SSIM(밴드 평균과 방식 명시), ERGAS(선택한 스케일 정의 명시), 재투영 오차. 장면별 수치와 **PCB 단위 평균·분산/신뢰구간**을 보고한다. 패치 평균을 독립 표본의 평균처럼 취급하지 않는다. 비정상 반사율·배경 마스크와 지표 적용 범위를 명시한다.
- 실제 센서 쌍: 출력 재열화와 관측 LR HSI의 차이, 밴드별 스펙트럼·경계 차이, 공통 시야 내 다중 밴드 시각화와 실패 사례. RGB와 HSI가 다른 조명/응답을 가지므로 RGB 일치 지표는 보조 진단일 뿐 HR HSI 품질의 정답 지표가 아니다.

## 실행된 작은 단계

```bash
cd SSA-MRN
.venv/bin/python scripts/inspect_pcb_pairs.py
.venv/bin/python scripts/make_pcb_split.py
.venv/bin/python scripts/evaluate_pcb_synthetic_baselines.py
```

첫 합성 수치는 **각 PCB의 중앙 128×128×224 HSI 패치 한 개**를 Gaussian σ=1.2로 흐린 뒤 32×32×224로 축소하고, 다시 128×128으로 확대한 값이다. PSNR은 반사율 단위에서 peak=1, SAM은 유효 유한 픽셀의 평균 각도다. 비정상값은 클리핑하지 않았다. 이 열화는 실제 Specim FX10의 PSF가 아니며, 숫자는 예비 실행 검증용이다.

| 13 | 28.30 dB / 5.12° | 30.66 dB / 4.83° |
| 27 | 29.47 dB / 5.22° | 32.47 dB / 4.88° |

## 다음 검증 관문

1. 헤더의 448개 파장과 실제 224개 채널의 대응을 공식 처리 코드/작성자 자료에서 확인한다. 46·47번의 파장 메타데이터 누락도 기록한다.
2. 5개 장면에서 수동 랜드마크를 먼저 잡아 회전·시야·잔차를 확인하고, 53개 전체 정합 가능성을 분류한다.
3. 유효 공통 시야가 확보된 장면으로만 RGB 가이드 합성 실험을 만들고, 정합 실패 장면의 실제 센서 실험은 별도 보고한다.
