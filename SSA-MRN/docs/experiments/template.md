이 파일을 `docs/experiments/실험명.md`로 복사하고 두 README의 실험 표에서 바로 연결합니다. 사전 검증·진행 중·학습 완료·전체 평가 완료를 구분하고 마지막 확인 시각을 적습니다.

## 1. 목적과 상태

가설, 시작/완료 상태, 코드 commit, run ID. 합성 축소 정량 평가인지 실제 센서 실험인지 명시합니다.

## 2. 변경 사항과 평가 조건

직전 실험에서 변경한 연산을 기술합니다. 데이터셋·독립 장면 수·분할과 ID 순서·파장/밴드·정합 및 마스크·값 범위·LR/HR 크기·축소/확대·타일 크기·K·학습 장치·best epoch를 기록합니다. 이 표는 설명 자료이며 폐기한 학습 JSON을 복제해 두지 않습니다.

<a id="results"></a>

## 3. 정량 결과

전체 test 장면 평균과 baseline. PAN–MS는 RR/FR 지표를 구분하고 MSE·PSNR·SAM의 계산 기준과 장면별 원본 JSON을 연결합니다. 표본 일부의 지표를 전체 평가로 표시하지 않습니다.

## 4. 직전 연구와 수치 차이

첫 실험을 제외하고 같은 지표에 직전 값, 현재 값, 차이(현재−직전)를 기록합니다. 평가 조건이 달라지면 관측 차이라는 사실과 달라진 항목을 반드시 적습니다. 비교 불가능한 다른 데이터셋의 수치는 N/A와 이유를 명시합니다.

<a id="graphs"></a>

## 5. 그래프

측정된 학습 MSE, validation PSNR/SAM 곡선과 test baseline 비교 그래프. 가능하면 직전 연구 비교를 추가하되 평가 조건 차이를 제목/설명에 표시합니다. 없는 epoch는 추정으로 채우지 않습니다.

<a id="images"></a>

## 6. 결과 이미지 예시

사전에 고정한 서로 다른 test 장면 5개의 **LR MS · PAN 입력 · 예측 · 정답** 4패널. 장면 ID/타일 번호/선택 seed를 적습니다. 모든 MS 패널에 동일 대비 범위, LR 표시에 최근접 확대를 사용합니다. 예측만 선명하게 보정하지 않습니다.

<a id="evidence"></a>

## 7. 가중치와 검증 근거

실제 학습된 best/latest 원본 `.pt`의 커밋 대상 포함 여부·보관 위치·SHA-256·epoch, 전체 지표 JSON, compact curves, selection, report manifest 링크. 외부 서버 파일이면 서버 경로임을 명시하고 Git에 있다고 주장하지 않습니다.

## 8. 한계와 다음 판단

관측값과 해석/가설을 구분합니다. RR 합성 축소 성능으로 FR 실제 해상도의 정답 정확도를 주장하지 않습니다. 종료 실험 설정/불필요 로그·캐시는 지우되 학습된 가중치와 숫자 결과는 보존합니다.
