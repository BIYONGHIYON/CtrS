# 9. 채널 축 교차 어텐션

**진행 결정:** 사용자 요청으로 이 설계의 학습을 생략합니다. 아래 설계는 미실행 자료로 보존하며 10번 PAN 재구성 오차 기반 보정으로 진행합니다. 자동 실행하지 않습니다.

연구 분야: **SSAI** · 연구 담당자·실험자: **이병현**

## 1. 목적과 상태

계획입니다. 8번의 학습·RR/FR 평가와 N2의 학습 가능화 성공은 확인했습니다. validation MSE가 낮은 N2를 B로 고정합니다. 원격 보관·복구 검증 완료가 선행 조건입니다. 충족 전 학습 코드는 실행하지 않습니다.

## 2. 바뀐 위치·입력·연산·출력과 비교 조건

밴드별 입력 PAN1채널, 현재 특징4채널+MS1채널과 출력K4를 유지합니다. 외부 backbone·fusion·복원 구조는 유지합니다. B는8번 N1/N2 중 validation MSE 최저이며 정확한 동률은N1입니다. B의 성능을 재사용하지만 X0/X1/X2는 모두 같은 공통 초기값에서 새로 학습합니다. 학습된 B로 warm start하지 않습니다.

X1은 C=16·heads=2인 채널 교차 어텐션입니다. `pan_feat=ReLU(Conv3x3(1,16))`; Qm은5→16 pointwise와 depthwise3×3, Kp/Vp는pan_feat의16→16 pointwise와 각각 depthwise3×3입니다. Qm/Kp를 공간축 L2 정규화(eps1e-6)하고, 헤드별 학습 온도 τ=1로 `A=softmax((Qm@Kp.T)*τ)`를 계산합니다. `A@Vp`를16→4 pointwise로 출력합니다. CCA는pan stem과최종출력만 bias=True, Q/K/V pointwise·depthwise는 bias=False, 온도는 직접 학습 스칼라로 사전 고정합니다. 추가 정규화·FFN·공간 softmax는 사용하지 않습니다.

X2는 B 정상화 블록과 X1의CCA를 병렬로 더하며 블록별 학습 γ=0.1로 `SSAI_B+γY`를 출력합니다. B 자체의gamma와 추가γ는 별도 기록합니다. X2 초기 출력은 B와 다릅니다.

X0는 원본 연산의 내부 폭을 **9**로 넓히고 B와 같은 공간 평균1 정규화 뒤9→4 pointwise로 출력합니다. C16으로 하면 X1보다 과도한 파라미터가 생겨 용량 대조가 안 되므로9로 조정했습니다. 출력K=4·공간4배는 유지합니다. B=N2이면 X0도 동일한 블록별gamma=.1을 적용합니다.

## 3. 정량 결과

실측 성능은 모두 미측정입니다. B 대비와 원본 A0 대비를 함께 기록하며 연산 효과는 X1 대 X0를 비교합니다. validation best(정확한 동률은 먼저 나온 에폭)로 고정하고 RR/FR test로 선택하지 않습니다.

## 4. 장면별 차이와 비교 이미지

RR20/FR20 전체와 장면별 차이를 평가합니다. FR 정답을 만들지 않습니다. QNR·Q2n·SCC는 잠정입니다. 실제 비교 이미지는 미측정입니다.

## 5. 파라미터·연산 비용과 실행

원본·X0는 bias=True, CCA는pan stem·최종출력만 bias=True 기준 사전 산술 계산입니다. 원본 블록은 등록1,032개 중 실제 사용372개이며 사용하지 않는 conv6t12가660개입니다. X0·X1은 교체 시 이 미사용 층을 보존하지 않습니다. 실제 모델 구현 후 다시 측정하며 미사용 파라미터로 수를 맞추지 않습니다.

| 후보 | 블록당 파라미터 | 원본 대비12블록 추가량 |
|---|---:|---:|
| 원본(등록 / 실제 사용) | 1,032 / 372 | 0 |
| X0 폭9, B=N1 | 1,282 | 3,000 |
| X0 폭9, B=N2 | 1,283 | 3,012 |
| X1 CCA16 | 1,254 | 2,664 |
| X2, B=N1 | 2,287 | 15,060 |
| X2, B=N2 | 2,288 | 15,072 |

X0/X1의 원본 대비 추가량 차이는 약12.6–13.1%로 ±15% 이내입니다. 실제 사용 파라미터 증가량은 X0가10,920(또는10,932), X1이10,584로 차이약3.2–3.3%입니다. B 대비 추가량도 별도로 보고합니다. 실제64·256·512 GMAC·시간·메모리는 미측정입니다. conv MAC만 보고할 경우 attention bmm를 별도 포함·표시하며 전체 비용과 혼동하지 않습니다.

## 6. 재현·원본 보존과 검증

QB seed42,100에폭,micro/effective32,FP32·결정론,Adam lr1e-4 일정,MSE,K4·공간4배·GPU85%/RAM15% 캐시를 유지합니다. 공통 초기값/학습 순서/RNG와 입력 데이터 해시를 확인합니다. 8번 B와 A0 지표는 같은 metric 정의가 확인될 때 재사용하며, 정의가 변경되면 동일 코드로 재평가합니다.

학습 전 후보별 입력·출력 크기, 유한 forward/backward, 추가 층을 생성해도 공통 초기값과 loader RNG가 같은지 확인합니다. GPU85% 캐시와micro32를 유지한 probe로 동시 실행 수를 정하며 세 개 동시 실행을 미리 확정하지 않습니다. 큰 입력의 batch/head 분할은 full 방식과 수치 일치 검증 후 적용합니다. 에폭별 validation MSE/SAM/global PSNR, 블록 출력/res RMS, 가중치 변화량, τ·γ를 기록합니다.

## 7. 결론과 한계

RR PSNR·SAM·ERGAS·잠정QNR이 함께 개선되면 개선, 엇갈리면 부분 개선입니다. 단일seed이며 자동 기준 승격하지 않습니다. X1이 X0보다 나쁘거나 차이가 일관되지 않으면 채널 어텐션 연산의 추가 이득 미확인으로 기록합니다. B 대비 개선이 있더라도 파라미터 증가로 설명 가능한지 검토하며 용량 효과를 단정하지 않습니다. projection·depthwise의 차이도 있어 순수 attention 하나의 인과 효과를 완전히 분리하는 대조는 아닙니다.

## 8. 남은 일과 연구 방향

8번의 원격 복구 검증 완료를 기다립니다. B=N2는 학습 가능화 성공을 통과했습니다. 실패하면9번 학습 없이 원인 진단만 보고합니다. 현재 model/train/checkpoint를 만들지 않았으며 모든 결과는 미측정입니다.
