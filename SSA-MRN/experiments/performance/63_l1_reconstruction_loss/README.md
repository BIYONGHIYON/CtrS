# 63. C2MS 학습 손실을 MSE에서 L1로 교체

**연구 분야:** 기존 성능 개선 · **실험자:** 이병현

**변경 내용:** 기준 모델 C2MS의 구조·축척 혼합·학습 일정은 그대로 두고, 원래 쌍과 2배 거친 쌍의 학습 손실만 MSE에서 L1(평균 절대 오차)로 바꿔 처음부터 학습합니다. QB seed 42로 먼저 선별합니다.

## 1. 목적과 상태

[성능 60-62번](../62_feature_context_band_ratio_head/README.md)에서 C2MS 출력 뒤에 붙이는 보정 헤드로는 SAM을 0.04° 넘게 줄이지 못했습니다. QB에서 SAM이 C2MS보다 낮은 단일 추론 모델(ARConv 4.430°, U2Net+PAKAN 4.439°, CANNet 4.507°)은 별도의 분광 모듈 없이 내용에 따라 바뀌는 합성곱과 **L1 손실**로 학습했습니다. C2MS는 MSE로 학습했으며, 저장소에서 주 손실을 L1로 바꾼 실험은 아직 없었습니다. L1은 모든 픽셀 오차에 같은 크기의 기울기를 주므로, 고주파의 밴드 비율처럼 작지만 넓게 퍼진 오차를 더 고르게 줄여 SAM을 낮출 수 있다는 가설입니다.

2026-10-26 사용자 승인 후 QB seed 42 학습을 서버에서 시작했습니다.

## 2. 변경한 구조와 비교 조건

| 항목 | C2MS (대조군) | 이번 후보 |
|---|---|---|
| 구조 | SSA-MRN K4 + W2 병렬 가지 (285만 개) | 같음 |
| 손실 | 원래 쌍 MSE + 1.0 × 거친 쌍 MSE | **원래 쌍 L1 + 1.0 × 거친 쌍 L1** |
| 학습 | 150에폭, Adam 1e-4 → 1e-6 cosine, batch 32, FP16 AMP(손실 FP32), channels_last | 같음 |
| 초기화·데이터 순서 | seed 42 | 같음 |
| 가중치 선택 | 원래 축척 validation MSE 최소(에폭 0 포함) | 같음 |

- **구현:** 성능 54번 학습기를 그대로 쓰고, 그 안의 제곱 오차 식 다섯 곳(학습 step, 거친 쌍 항, 벤치마크, preflight)만 절대 오차로 바꿉니다. 각 치환은 정확히 한 번 일치해야 하며, 나머지 코드는 같습니다([train.py](train.py)). 기록의 `train_mse` 이름은 54번 그대로지만 값은 평균 절대 오차입니다.
- **거친 쌍의 상대 비중:** 가중치를 똑같이 1.0으로 두면 L1에서는 거친 쌍 항의 비중이 MSE보다 커집니다. QB에서 MSE는 거친 쌍이 원래 쌍의 약 0.26배이고, L1은 약 0.5배로 예상합니다. 실제 비율은 학습 기록에서 확인해 보고합니다.

### 대조군을 다시 학습하지 않는 이유

공식 대조군은 보관된 [성능 53번](../53_scale_mixed_training/README.md) C2MS(같은 시드)입니다. [성능 57번](../57_c2ms_training_conditions/README.md)에서 같은 시드로 C2MS를 다시 학습했을 때, 53번 대비 RR은 PSNR +0.009 dB·SAM −0.003°·ERGAS −0.004로 거의 같았습니다. 반면 RR2는 −0.306 dB, 관측 비율은 1.124로 크게 흔들렸습니다. 주 판정에는 보관된 대조군이면 충분하고, 보조 판정의 흔들림은 대조군을 한 번 더 돌려도 없어지지 않으므로 3시드 평균으로 판정합니다.

선별 단계에서는 57번 재학습 C2MS(seed 42)를 두 번째 참조로 함께 보고합니다. 3시드 결과의 보조 판정이 허용폭 ±0.02 dB 안의 경계에 걸리면, 같은 코드로 3시드 대조군을 추가합니다.

### 단계와 관문 (학습 전에 고정)

| 단계 | 내용 | 다음으로 가는 조건 |
|---|---|---|
| 1 선별 | QB seed 42 (약 3.6시간) | 53번 대비 test RR SAM ≤ −0.05°이고 RR PSNR ≥ −0.04 dB, validation도 같은 방향 |
| 2 반복 | QB seed 43·44 추가, 53번과 짝지은 3시드 v2.3 | 개선 또는 SAM 목표 달성 |
| 3 확장 | GF2·WV3 3시드와 WV2 전이 | 사용자 승인 후 |

판정은 [판정 기준](../../../docs/judgement_criteria.md) v2.3을 그대로 쓰고, SAM 목표(ΔSAM ≤ −0.15°, ΔPSNR ≥ −0.04 dB)는 따로 보고합니다. 설정은 [config.json](config.json)에 있습니다.
