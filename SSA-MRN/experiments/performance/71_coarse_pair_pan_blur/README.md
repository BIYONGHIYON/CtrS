## 1. 목적과 상태

PSNR·SAM 동시 개선과 WV2 전이를 검증합니다. 사용자께서 2026-10-29 단일시드 실행을 지시했습니다. 별도 폴더 C:/CtrS-p70-71에서 독립 컨트롤러를 16:53 KST에 시작했습니다. 70번 4회 후 71번 2회 순서입니다.

## 2. 변경한 구조와 비교 조건

BLUR_BOTH는 원래·거친 쌍 각각 확률 0.25, BLUR_COARSE는 거친 쌍만 확률 0.50로 PAN Gaussian 흐림을 적용합니다. sigma는 0-1.2픽셀입니다. WV3 seed 42, 총 2회이며 70번 C2MS_R 대조군을 공유합니다.

모두 새 초기화·MSE·거친 쌍 가중치 1·150에폭·Adam·cosine 1e-4에서 1e-6·batch 32를 사용합니다. 추론은 단일 모델 한 번입니다. 체크포인트는 clean validation MSE로 선택합니다. 선별 기준은 config.json에 고정하며 WV2 test로 강도나 후보를 고르지 않습니다.

## 3. 정량 결과

미측정입니다. 공식 대조군은 53·54번 C2MS이며 같은 실행기의 70번 재학습 대조군 비교를 함께 기록합니다. 단일시드 PSNR 문턱은 0.06 dB입니다. QB RR2는 57번 고정 대조값을 유지합니다. RR·RR2·FR_WALD·FR_OBS 및 WV2 전이를 평가합니다.

## 4. 기준선 대비 차이와 해석

67번은 WV2 PSNR +1.025 dB였지만 WV3 -0.204 dB 및 WV2 RR2 SAM 미달이었습니다. 두 후보의 손실 항 기준 기대 증강 노출량을 맞춰 총량과 위치의 효과를 구분합니다. 픽셀 수가 같은 것은 아닙니다.

## 실행 복구 (2026-10-30)

70번 네 학습을 마친 뒤 validation.py가 공통 모듈 경로를 등록하지 않아 검증 시작에서 중단됐습니다. 네 실행의 epoch 150·완료 fingerprint·best SHA-256·학습 당시 소스 해시를 확인했습니다. 서버의 봉인 소스는 유지하고 외부 복구 실행기에 PYTHONPATH=SSA-MRN을 설정해 validation부터 재개했습니다. 71번은 이 환경을 그대로 상속합니다. 재학습이나 새 시드 추가는 하지 않습니다.

현행 validation.py에는 학습 실행기와 같은 모듈 검색 경로를 명시했습니다. 배포 당시 원본은 provenance/recovery_20261030/validation_original.py에 보존합니다. 70번 provenance/recovery_20261030에는 독립 복구 실행기·실행 전 체크포인트 감사·launcher 기록이 있습니다. 테스트 결과와 71번 학습 완료는 아직 확인하지 않았습니다.
