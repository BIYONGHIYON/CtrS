## 1. 목적과 상태

## 2. 변경한 구조와 비교 조건

C2MS_R은 그대로 재학습합니다. C2MS_D는 원래 해상도 가지의 블록 2·4 두 번째 합성곱만 dilation 2·padding 2로 바꿉니다. W2는 유지합니다. QB·WV3 seed 42, 총 4회입니다.

모두 새 초기화·MSE·거친 쌍 가중치 1·150에폭·Adam·cosine 1e-4에서 1e-6·batch 32를 사용합니다. 추론은 단일 모델 한 번입니다. 체크포인트는 clean validation MSE로 선택합니다. 선별 기준은 config.json에 고정하며 WV2 test로 강도나 후보를 고르지 않습니다.

## 3. 정량 결과
