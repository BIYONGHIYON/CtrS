# 91. 학습 센서별 가중치의 밴드 보정 전이 진단

| 분야 | 실험자 | 상태 | 판정 |
|:---:|:---:|:---:|:---:|
| 성능 개선 | 이병현 | 계획 | **성능 비교 아님** |

**변경:** 성능 90번의 QB·GF2 `CK` 가중치(seed 42)를 CAS500-1 L2G의 같은 고정 FR 패치에 적용합니다. 재학습하지 않으며 성능 82번의 밴드별 입력 통계 보정을 적용합니다. 대상 영상의 밴드별 실측 MTF가 확정되지 않아 관측 일치 사영은 제외합니다. 따라서 완전한 SMOC와 구분한 사전 진단입니다.

**결과:** 아직 추론하지 않았습니다. 하나의 촬영 장면에서 좌표만으로 고른 20개 진단 패치를 비교하며, 나머지 영역은 이번 가중치 비교에 사용하지 않습니다. GT와 RR 수치는 만들지 않습니다.

[실험 표](../README.md#experiments) · [결과](#results) · [해석과 판정](#verdict) · [방법](#method) · [그림](#figures) · [재현 자료](#evidence)

<a id="results"></a>

## 결과

추론 대기입니다. 동일 패치의 예측과 참고 FR QNR·Dλ·Ds를 보관합니다. 이 지표만으로 학습 센서의 우열이나 개선을 판정하지 않습니다.

<a id="verdict"></a>

## 해석과 판정

성능 비교가 아닌 전이 동작 사전 진단입니다. 독립 촬영 장면은 1개이며, 패치 수를 독립 장면 수로 세지 않습니다. 본 결과로 기준 모델을 바꾸지 않습니다.

<a id="method"></a>

<details>
<summary><b>방법</b> · 고정 조건과 적용 범위</summary>

- QB_CK·GF2_CK seed 42, 동일 4밴드(B·G·R·NIR), 학습 센서의 모델 내부 MTF를 유지합니다.
- 입력은 `DN / 4095`, 클리핑하지 않은 float32입니다. PAN 512×512, MS 128×128, LMS는 원본 주변 영역을 사용한 23탭 보간입니다.
- MS 좌표 기준 장면 위쪽 1/3 안에 완전히 포함된 패치에서 좌표의 최대 최소거리 규칙으로 20개를 고릅니다. 예측·지표·영상 내용을 보고 고르지 않습니다.
- 밴드 보정은 성능 82번의 학습 세트 기준 비율과 각 512×512 패치의 입력 평균으로 계산합니다. PAN의 절대 밝기는 바꾸지 않습니다.
- 관측 일치 사영·RR 축소·GT·재학습·test 기반 가중치 선택은 없습니다.
- 문헌의 MTF 하한값과 시뮬레이션 가정값은 이번 L2G 영상의 밴드별 실측 MTF로 간주하지 않습니다.

</details>

<details>
<summary><b>그림</b> · 동일 표시 조건의 비교</summary>

추론 후 진단 순번 0·1·3·7·14·17을 고정해 LMS·PAN·QB·GF2를 비교합니다. RGB 표시 척도는 입력 LMS에서 정한 값을 두 후보에 공통 적용합니다. 학습 곡선과 FR 정답은 없습니다.

</details>
