# 91. 학습 센서별 가중치의 밴드 보정 전이 진단

| 분야 | 실험자 | 상태 | 판정 |
|:---:|:---:|:---:|:---:|
| 성능 개선 | 이병현 | 사전 검증 완료 | **성능 비교 아님** |

**변경:** 성능 90번의 QB·GF2 `CK` 가중치(seed 42)에 성능 82번의 밴드별 보정을 붙여 CAS500-1 L2G의 같은 고정 FR 패치에 적용했습니다. 사영 없는 예측을 먼저 비교한 뒤, 두 예측 모두에 사전 고정한 MS MTF 0.26 가정의 관측 일치 사영을 추가했습니다. 재학습하지 않았으며, 실측 MTF를 사용하는 완전한 SMOC 평가와 구분합니다.

**결과:** 한 촬영 장면의 고정 FR 20패치에서 참고 QNR은 QB가 사영 전 0.861012에서 후 0.892352로 올랐고, GF2는 0.960222에서 0.948545로 내렸습니다. 네 설정 중 GF2 무사영의 평균 QNR이 가장 높았습니다. 가정한 연산자에 대한 MS 관측 잔차는 둘 다 줄었습니다. GF2 무사영을 다음 검증의 우선 후보로 두며, GT·RR 개선이나 전체 센서 전이의 우열을 판정하지 않습니다.

## 결과

CAS500-1 L2G 한 장면의 고정 20패치 평균입니다. 두 후보 모두 성능 90번 `CK` seed 42에 성능 82번 보정을 적용하고 사영을 제외했습니다. 독립 촬영 장면 수는 1입니다. 아래 수치는 저장소의 Python FR 지표이며 참고용입니다.

| 지표 | QB 학습 가중치 | GF2 학습 가중치 | GF2 − QB | GF2가 유리한 패치 |
|---|---:|---:|---:|---:|
| QNR ↑ | 0.861012 | 0.960222 | +0.099210 | 20/20 |
| Dλ ↓ | 0.055736 | 0.021549 | −0.034186 | 19/20 |
| Ds ↓ | 0.088359 | 0.018675 | −0.069684 | 20/20 |

QNR의 패치별 차이는 +0.046630에서 +0.177690입니다. 패치들은 같은 촬영 장면에서 나왔으므로 독립 표본의 통계적 유의성으로 해석하지 않습니다. 장면별 자료는 [summary.json](results/summary.json)에 있습니다.

### 입력 보간과 세부 변화 (참고)

보간 LMS 자체의 QNR은 0.901738입니다. 이것이 QB보다 높다는 사실은 QNR만으로 복원 정확도를 판단해서는 안 되는 이유입니다.

| 설명 지표 | QB | GF2 |
|---|---:|---:|
| 출력 고주파 RMS / 입력 LMS 고주파 RMS | 15.426 | 6.331 |
| 밴드 평균의 상대 변화 절댓값 평균 | 1.342% | 0.177% |

고주파는 `영상 − Gaussian(σ=1 px)`의 RMS입니다. 추론이 끝난 뒤 고정 패치에서 계산한 설명 지표이며, 설정·패치 선택에 사용하지 않았습니다. 두 후보 모두 보간보다 고주파가 증가했지만, 그 세부가 정확하다는 뜻은 아닙니다. 정의와 패치별 값은 [descriptive_diagnostics.json](results/descriptive_diagnostics.json)에 있습니다.

### 가정 MTF 사영 비교

기존 예측에 같은 사영을 적용했습니다. 입력·가중치·20패치 목록과 사영 없는 결과는 유지했습니다. 다음 값은 같은 패치의 전후 비교이며 모두 Python 참고 지표입니다.

| 학습 가중치 | QNR 전 → 후 ↑ | QNR 차이 | Dλ 전 → 후 ↓ | Ds 전 → 후 ↓ | 가정 MS 잔차 RMSE 전 → 후 (DN) |
|---|---:|---:|---:|---:|---:|
| QB | 0.861012 → 0.892352 | +0.031341 | 0.055736 → 0.044218 | 0.088359 → 0.066546 | 30.1769 → 1.3697 |
| GF2 | 0.960222 → 0.948545 | −0.011676 | 0.021549 → 0.026464 | 0.018675 → 0.025744 | 11.7840 → 0.9766 |

QNR이 오른 패치는 QB 19/20개, GF2 4/20개입니다. 관측 잔차는 두 가중치의 40개 출력 모두 줄었고 공액 기울기법은 모두 10회 실행됐습니다. 관측 잔차 감소는 가정한 연산자와의 일치이며 복원 정확도 개선을 뜻하지 않습니다. 패치별 값은 [projection_summary.json](results/projection_summary.json)에 있습니다.

[사전 고정 계획](provenance/projection_plan.json): MS 각 밴드 GNyq 0.26, 기존 41×41 커널·4배 축소·위상 (2,2), 경계 5 MS 픽셀 제외, 기존 공액 기울기법 최대 10회(허용오차 1e-8), CPU float64입니다. 사영에는 PAN 축소를 사용하지 않아 PAN MTF는 새로 가정하지 않았습니다. 출력은 클리핑하지 않았습니다.

0.26은 문헌의 시뮬레이션 가정이며 L2G 실측값이 아닙니다. 원 논문이 RGB 항공영상을 사용했으므로 NIR에도 0.26을 적용한 부분은 추가 가정입니다. 이 결과를 보고 MTF나 패치 목록을 다시 고르지 않았습니다.

<a id="verdict"></a>

## 해석과 판정

사영 없는 고정 FR 진단에서는 GF2가 입력의 밴드 평균을 더 잘 유지하면서 두 왜곡 지표와 QNR이 전반적으로 유리했습니다. 같은 표시 척도의 첫 고정 패치에서 QB는 세부 대비가 더 강하고 GF2는 상대적으로 완만했습니다. 정답이 없어 어느 쪽의 세부가 실제 지표면에 더 정확한지는 확인할 수 없습니다.

가정 사영 후에도 평균 QNR은 GF2 무사영보다 낮았습니다. 다음 CAS500 검증의 우선 후보는 GF2_CK 무사영으로 두되, QB_CK를 동일 조건 비교군으로 남깁니다. 이는 validation 성격의 사전 진단에서 정한 실행 우선순위이며, test 기반 최종 가중치 선택이나 개선 판정이 아닙니다. 원본 SSA-MRN과의 비교도 이번 진단에는 포함하지 않았습니다.

### 한계와 다음 확인

- 대상 영상의 밴드별 MTF와 사영 조건을 고정한 뒤 RR·FR을 다시 평가해야 합니다.
- 독립 촬영 장면 수는 1이며, 추가 지역·날짜와 별도 평가 영역이 필요합니다.
- seed 42 하나입니다. 이 결과로 기준 모델을 바꾸지 않습니다.
- Python QNR은 참고 지표입니다. PSNR·SAM·ERGAS는 계산하지 않았습니다.
- 학습 센서의 내부 MTF는 유지했습니다. 사영 추가 비교도 대상 센서의 실측 MTF를 사용하지 않아 완전한 SMOC 평가로 표시하지 않습니다.

<a id="method"></a>

<details>
<summary><b>방법</b> · 고정 조건과 적용 범위</summary>

- QB_CK·GF2_CK seed 42, 동일 4밴드(B·G·R·NIR), 학습 센서의 모델 내부 MTF를 유지합니다.
- 입력은 `DN / 4095`, 클리핑하지 않은 float32입니다. PAN 512×512, MS 128×128, LMS는 원본 주변 영역을 사용한 23탭 보간입니다.
- MS 좌표 기준 장면 위쪽 1/3 안에 완전히 포함된 패치에서 좌표의 최대 최소거리 규칙으로 20개를 고릅니다. 예측·지표·영상 내용을 보고 고르지 않습니다.
- 밴드 보정은 성능 82번의 학습 세트 기준 비율과 각 512×512 패치의 입력 평균으로 계산합니다. PAN의 절대 밝기는 바꾸지 않습니다.
- 첫 진단은 사영을 제외했고, 추가 비교는 사전에 고정한 가정 MTF 사영을 두 후보 모두에 적용했습니다. RR 축소·GT·재학습·test 기반 가중치 선택은 없습니다.
- 문헌의 MTF 하한값과 시뮬레이션 가정값은 이번 L2G 영상의 밴드별 실측 MTF로 간주하지 않습니다.

</details>

<details>
<summary><b>그림</b> · 동일 표시 조건의 비교</summary>

진단 순번 0·1·3·7·14·17을 고정해 LMS·PAN·QB·GF2 비교 이미지를 만들었습니다. RGB 표시 척도는 입력 LMS의 채널별 2-98백분위에서 정한 값을 두 후보에 공통 적용했습니다. 사영 비교는 같은 순번의 LMS·QB 전후·GF2 전후 다섯 열입니다. 학습 곡선과 FR 정답은 없습니다. 원본 영상이 포함된 그림과 예측 배열은 로컬에 보관하고 위치·크기·해시는 manifest에 기록했습니다.

</details>

<a id="evidence"></a>

<details>
<summary><b>재현 자료</b> · 설정·해시·실행 자료</summary>

[설정](config.json)과 좌표로 고른 패치 목록을 추론 전에 고정했습니다. 예측 HDF5 두 개를 모두 다시 읽어 유한값·패치 순서를 확인했습니다. 원본 영상·정규화 패치·예측 배열은 Git에 넣지 않으며, 경로·SHA-256과 소스 근거를 [manifest](manifest.json)에 기록했습니다. 관련 이슈: [#235](https://github.com/BIYONGHIYON/CtrS/issues/235).

재학습하지 않아 새 체크포인트와 학습 곡선은 없습니다. 성능 90번의 보관 가중치를 사용했습니다. 모델 추론은 로컬 Apple Metal GPU float32, 사영은 CPU float64로 실행하고 float32로 저장했습니다. [실행 코드](run.py), [입력 전처리 소스](provenance/prepare_input.py), [입력 전처리 manifest](provenance/data_manifest.json), [소스·가중치 근거](provenance/source_manifest.json)를 보관했습니다.

사영은 [evaluate.py](evaluate.py)로 실행합니다. 사영의 직접 합성곱 대비 최대 오차는 1.17e-15, 수반 내적 상대 오차는 1.96e-15였고 잔차 0인 입력은 변하지 않았습니다([검증](results/projection_preflight.json)). 사영 예측 두 파일의 모든 패치도 다시 읽어 유한값과 순서를 확인했습니다. 사영의 고정 계획·소스 해시는 [추가 근거](provenance/projection_source_manifest.json)에 있습니다.

MTF 검토 근거: [CAS500-1 검보정 논문](https://doi.org/10.3390/rs18010177)은 보정 전후 MTF의 하한값을 제시하고, [CAS500 초해상도 데이터 생성 논문](https://doi.org/10.7780/kjrs.2023.39.4.6)은 시뮬레이션에 0.26을 가정했습니다. 이 값들을 이번 L2G의 밴드별 실측 MTF로 사용하지 않았습니다.

</details>

<details>
<summary><b>동국대 주변 시각화</b> · QB 무사영 모자이크</summary>

동국대 서울캠퍼스 주변을 QB 무사영으로 팬샤프닝해 **2,560×2,688픽셀**로 합성했습니다. 명목 PAN GSD 0.5m 기준 약 1.28×1.344km입니다. 사용자 지정 지역의 시각화이며 성능 비교가 아닙니다. 기존 고정 20패치와 수치는 바꾸지 않았습니다.

[고정 계획](provenance/mosaic_plan.json)에 따라 512픽셀 입력 타일 100개의 가장자리 64픽셀을 제외하고, 384픽셀 코어를 stride 256으로 겹쳐 Hann 가중 합성했습니다. 밴드 보정 계수와 RGB 표시 척도는 전체 ROI에서 하나씩 계산해 모든 타일에 공유했습니다. 개별 밴드에 흩어진 원본 0 DN은 채우거나 지우지 않고 유지했습니다.

전체 영역의 피복·유한값, 원본 halo 보간의 일치, PNG 형식, 4밴드 float32 DN TIFF의 정확한 재읽기를 확인했습니다. 그림과 예측은 로컬에 보관하고 SHA-256을 manifest에 기록했습니다. RGB 표시에서만 범위를 잘라내며, 4밴드 DN TIFF에는 출력의 음수와 명목 최대값 초과값도 보존했습니다. 출력은 원본 픽셀 좌표를 기준으로 하며 지리참조 정확도는 인증하지 않습니다.
