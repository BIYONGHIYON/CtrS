# 92. 외부 모델에서 밴드별 밝기 보정과 관측 일치 사영의 효과 검증

| 분야 | 실험자 | 상태 | 판정 |
|:---:|:---:|:---:|:---:|
| 성능 개선 | 김경찬 | 평가 완료 | **성능 비교 아님** |

**변경**
ADWM, ARConv, CANNet, FusionNet, U2Net의 WV3 저자 가중치로 WV2에 전이했습니다. 모델별로 원본, 밴드별 밝기 보정만, 관측 일치 사영만, 두 보정 동시 적용을 비교했습니다. 네 조건에서 모델 가중치를 고정했으며 재학습하지 않았습니다.

**결과**
WV2 RR test 20장 평균에서 다섯 모델 모두 두 보정을 함께 적용했을 때 PSNR·SAM·ERGAS가 네 조건 중 가장 좋았습니다. 원본 대비 평균 PSNR은 1.75-3.08 dB, 밝기 보정 단독 대비 0.08-0.33 dB 향상됐습니다.

## 결과

각 칸은 PSNR(dB) / SAM(°) / ERGAS입니다. PSNR은 높을수록, SAM과 ERGAS는 낮을수록 좋습니다.

## 해석과 판정

다섯 모델에서 밝기 보정 단독이 PSNR 개선 폭의 대부분을 설명했습니다. 밝기 보정에 관측 일치 사영을 더했을 때 PSNR은 ADWM +0.2598, ARConv +0.0760, CANNet +0.0958, FusionNet +0.3296, U2Net +0.0882 dB 향상됐으며, 평균 SAM과 ERGAS도 모두 낮아졌습니다. 이 결과는 WV3 저자 가중치를 적용한 WV2 RR 20장에 한정됩니다. 다른 센서와 FR 조건의 효과는 이번 평가 범위 밖입니다.

<details>
<summary>방법</summary>

- 원본과 보정 조건은 모델별로 동일한 WV3 저자 가중치와 동일한 WV2 RR 장면 0-19를 사용했습니다.
- 입력을 2047로 정규화하고, 복원 결과를 원래 척도로 환산한 뒤 CtrS Python 평가기로 채점했습니다.
- 밝기 보정은 실험 82의 WV3 기준 통계와 WV2 입력 장면 통계를 사용했습니다. 모델 출력은 WV2의 원래 밝기 척도로 복귀시켰습니다.
- 관측 일치 사영은 실험 83의 K10 설정과 WV2 관측 연산자를 사용했습니다. 두 보정을 함께 적용할 때도 사영의 기준은 보정 전 WV2 MS입니다.
- ADWM·ARConv·FusionNet·U2Net은 Windows CPU, CANNet은 Kaggle Tesla T4 한 개에서 추론했습니다. 관측 일치 사영은 CPU에서 계산했습니다.
