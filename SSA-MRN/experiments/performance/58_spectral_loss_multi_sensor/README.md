# 58. 기준 모델 C2MS에 분광 손실을 더한 학습의 반복 시드·다른 센서 확인

**연구 분야:** 기존 성능 개선

**실험자:** 이병현

**변경 내용:** [성능 57번](../57_c2ms_training_conditions/README.md)에서 seed 42로 SAM을 20/20장 낮춘 분광 손실(0.01 × 픽셀별 1 − cosine)을 C2MS에 더해, QB seed 43·44와 GF2·WV3 seed 42-44로 학습합니다(QB seed 42는 57번 실행을 그대로 씀). 같은 시드의 53번(QB)·54번(GF2·WV3) C2MS와 짝지은 3시드 평균으로 판정하고, WV3 모델은 WV2 전이도 평가합니다.

| 확인된 결과 | 상태 | 개선 여부 |
|---|:---:|:---:|
| 아직 평가하지 않았습니다. | 학습&nbsp;중<br>10-24&nbsp;04:34 | 판단&nbsp;보류 |

## 1. 목적과 상태

57번에서 분광 손실은 seed 42 RR PSNR +0.035 dB·SAM −0.048°로 잡음 문턱 근처의 부분 개선이었습니다. 효과가 시드 변동을 넘는지, 다른 센서에서도 유지되는지 확인합니다. 판정 방법은 학습 전에 [config.json](config.json)의 `judgement`에 고정했고, 학습은 2026-10-24 사용자 승인 후 04:17(KST)에 시작했습니다. 8개 실행(QB 2, GF2 3, WV3 3)을 한 번에 하나씩 150에폭 학습하며 2026-10-25 오전 종료를 예상합니다.

## 2. 변경한 구조와 비교 조건

학습 코드·설정은 57번 C2MS_SAM과 같습니다([model.py](model.py), [train.py](train.py), [run.py](run.py), [prepare.py](prepare.py)). 결과·보고서는 학습과 평가가 끝난 뒤 이 문서의 8개 절로 작성합니다.
