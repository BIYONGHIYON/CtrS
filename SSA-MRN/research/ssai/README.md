# SSAI 개선

[전체 연구](../../../README.md) · [실행·등록 안내](../../README.md#새-실험-등록)

**담당: 이병현**

밴드별 공간·분광 특징을 결합하는 SSAI의 연산과 구조를 개선합니다.

## 현재 상태

**계획 · 실험 미착수**입니다. 새 분담에 따른 SSAI 개선 실험은 아직 등록하지 않았습니다.

## 연구 범위

SSAI에서 PAN의 공간 정보와 MS의 밴드별 분광 정보를 결합하는 입력·연산·출력을 비교합니다. 먼저 원본 SSAI를 대조군으로 두고 변경 위치와 가설을 정합니다. 바꿀 연산과 학습 조건은 각 실험 계획에서 확정합니다.

내부 특징 차원 K와 영상의 확대 배율은 서로 다른 값입니다. SSAI 개선 효과를 비교할 때 실제 K·배율·센서·데이터 분할·시드를 기록하고, 구조 외 조건을 함께 바꾸면 그 영향을 별도로 설명합니다.
