# 성능 개선

[전체 연구](../../../README.md) · [실행·등록 안내](../../README.md#새-실험-등록)

각 실험의 실제 실험자는 표의 첫 열에 표시하며, 과거 실험의 실험자는 바꾸지 않습니다. SSAI 개선(2026-10-16)과 가변 배율 확장(2026-10-27)은 종료했습니다.

## 연구 범위

기존 복원 구조·학습 방법·손실 등의 수치 개선을 계속 비교합니다.

같은 센서·배율·데이터·학습 조건의 대조군과 비교합니다. 2026-10-21부터 기준 모델은 [성능 53번](../../experiments/performance/53_scale_mixed_training/README.md)의 C2MS(원본 SSA-MRN K4 + W2 병렬 가지, 원래·2배 거친 학습 쌍 축척 혼합 학습)이며, 새 실험의 대조군은 C2MS입니다. 이전 기준 모델은 [성능 49번](../../experiments/performance/49_observation_refinement_seed_repeat/README.md)의 F1(2026-10-20)입니다. validation으로 후보와 가중치를 선택하고, 개선 여부는 [판정 기준 v2.3](../../docs/judgement_criteria.md)(RR 주 판정과 RR2·FR_WALD·FR 관측 일치 보조 판정)으로 정합니다. 단일 시드도 모든 항목을 통과하면 개선으로 표기하고, 여러 시드는 같은 조건 대조군과 짝지은 전체 시드의 평균으로 판정합니다. 시드 수·시드별 결과를 함께 보고하며, 기준 모델 교체에는 3시드 이상에서 개선이 필요합니다. 기존 표도 [성능 47번 재평가](../../experiments/performance/47_ground_truth_criteria_reevaluation/README.md)의 보존된 측정값을 v2.3으로 다시 집계해 반영합니다. 현재 표의 판정 범위는 QB이고, 다른 센서의 결과는 원래 보고서에서 확인합니다. 보조 판정 자료가 없는 성능 비교는 판단 보류입니다. 여러 후보 중 개선 후보가 있으면 해당 이름을 표시하며, 개선 표기만으로 기준 모델을 바꾸지 않습니다.

## 실험 폴더와 네이밍

각 실험의 코드·보고서·가중치·결과는 이 연구 폴더 아래 `<번호>_<영문 변경명>/`에 함께 보관합니다. 세 연구 모두 정수 번호와 소문자 snake_case 변경명을 사용합니다.

가설이 다른 실험은 별도 폴더로 나누고 같은 가설의 후보·센서·반복 시드는 같은 실험의 `checkpoints/`와 `results/` 아래에서 구분합니다. 연구 목록은 이 페이지의 표에 추가하고 다른 분야에서는 복제하지 않고 보고서로 연결합니다.
