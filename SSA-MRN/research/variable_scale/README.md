# 가변 배율 확장

[전체 연구](../../../README.md) · [실행·등록 안내](../../README.md#새-실험-등록)

**담당: 김윤지**

기존 고정 4배 복원을 여러 배율에서 동작하도록 확장합니다.

## 현재 상태

**계획 · 실험 미착수**입니다. 지원 배율·모델 구성·학습 계획은 아직 확정하지 않았습니다.

## 연구 범위

기존 기준 모델은 가로·세로 각각 4배의 고정 배율을 사용합니다. 가변 배율 연구에서는 목표 크기와 배율에 맞춰 입력·보간·관측·출력을 정의하고 복원 성능을 확인합니다.

실험을 시작할 때 다음 조건을 기록합니다.

- 학습 배율과 평가 배율, 학습에서 본 배율과 보지 않은 배율
- 단일 모델의 여러 배율 지원인지, 배율별 별도 모델인지
- PAN·MS·LMS·출력의 실제 크기, 보간·열화·정렬 및 경계 처리
- 배율마다 동일한 조건으로 비교할 대조군, 데이터 분할·validation 선택 기준

정수·비정수 배율 지원이나 미학습 배율 일반화는 실제 검증한 범위만 보고합니다. RR·FR 수치는 배율별로 표시하며, FR에는 정답을 만들지 않습니다. 기존 고정 4배 결과는 해당 조건의 참고 기준으로 사용합니다.

## 실험 폴더와 네이밍

각 실험의 코드·보고서·가중치·결과는 이 연구 폴더 아래 `<번호>_<영문 변경명>/`에 함께 보관합니다. 세 연구 모두 정수 번호와 소문자 snake_case 변경명을 사용합니다. 번호는 저장소 전체에서 공유하며 최신 main과 열린 PR을 확인한 뒤 마지막 번호 다음을 사용합니다. 분야별로 1부터 다시 시작하지 않습니다.

가설이 다른 실험은 별도 폴더로 나누고 같은 가설의 후보·센서·반복 시드는 같은 실험의 `checkpoints/`와 `results/` 아래에서 구분합니다. 연구 목록은 이 페이지의 표에 추가하고 다른 분야에서는 복제하지 않고 보고서로 연결합니다.
