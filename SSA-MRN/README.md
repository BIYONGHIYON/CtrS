# SSA-MRN 기반 고해상도 초분광 영상 제작

> 원본 문서: [Notion — SSA-MRN 기반 고해상도 초분광 영상 제작](https://app.notion.com/p/SSA-MRN-3e113c366e4580d09b45ef5980dfdd4d?source=copy_link)

## 연구 요약

고해상도 RGB 영상의 공간 정보와 저해상도 초분광 영상(HSI)의 분광 정보를 융합해 고해상도 HSI를 복원합니다. 기존 SSA-MRN의 밴드별 분광–공간 어텐션과 다중 해상도 점진적 융합 원리를 RGB–HSI 문제에 맞게 변형합니다.

핵심 질문은 다음과 같습니다.

> SSA-MRN의 핵심 구조를 RGB 유도 HSI 초해상도 문제에 적용했을 때, 단순 보간 또는 일반적인 융합 모델보다 공간 선명도와 분광 보존 성능을 함께 향상할 수 있는가?

## 1. 연구 배경

일반 RGB 영상은 넓은 파장 범위를 Red, Green, Blue의 세 채널로 기록합니다. 반면 HSI는 연속된 파장 영역을 수십~수백 개의 좁은 밴드로 나누어 기록합니다. 물질마다 파장별 반사·흡수 특성이 달라 RGB에서 비슷하게 보이는 물질도 HSI에서는 구분할 수 있습니다.

HSI는 식품 품질 검사, 농작물 상태 분석, 환경 모니터링, 의료·조직 분석과 문화재 분석 등에 활용됩니다. 작은 결함과 세부 구조를 분석하려면 분광 정보뿐 아니라 충분한 공간 해상도도 필요하지만, 많은 HSI 촬영 방식은 높은 분광 해상도를 얻는 대신 공간 해상도나 촬영 속도에 제약이 있습니다.

- 고해상도 RGB: 선명한 형태, 경계와 질감 정보
- 저해상도 HSI: 물질을 구분하는 파장별 분광 정보

RGB의 경계가 HSI의 모든 밴드 경계와 항상 일치하는 것은 아닙니다. 따라서 RGB 세부 정보를 그대로 복사하지 않고 각 HSI 밴드와 관련된 공간 정보만 선택적으로 반영해야 합니다.

## 2. 연구 문제와 목표

### 입력과 출력

- 입력 1: 고해상도 RGB 영상
- 입력 2: 저해상도 HSI
- 출력: 고해상도 HSI

### 연구 목표

1. RGB의 공간 정보를 이용해 HSI의 경계와 세부 형태를 복원합니다.
2. 해상도를 높이는 과정에서 HSI의 파장별 특성이 왜곡되지 않도록 합니다.
3. SSA-MRN 기반 모델이 단순 보간과 일반 융합 모델보다 유효한지 정량적으로 검증합니다.

## 3. SSA-MRN과 제안 모델

### 기존 SSA-MRN

SSA-MRN은 저해상도 다중분광 영상(MS)과 고해상도 전정색 영상(PAN)을 결합해 고해상도 MS 영상을 만드는 펜샤프닝 모델입니다.

1. **입력 준비:** LR-MS는 분광 정보를, HR-PAN은 선명한 공간 정보를 제공합니다.
2. **특징 추출:** ResNet 블록이 경계, 질감, 밝기와 색 변화를 학습합니다.
3. **밴드별 SSAI:** 각 MS 밴드를 PAN 특징과 별도로 비교해 관련성이 높은 공간 특징을 선택합니다.
4. **다중 해상도 처리:** 낮은 해상도에서 큰 구조를, 높은 해상도에서 작은 경계와 질감을 복원합니다.
5. **점진적 융합:** 큰 구조부터 세부 구조까지 순차적으로 결합하고 원래 MS 정보를 더합니다.

### 제안하는 확장 모델

```text
HR RGB ───────────────┐
                     ├─ 특징 추출 ─ 밴드별 RGB 관련성 계산 ─ 다중 해상도 점진적 융합 ─ HR HSI
LR HSI ───────────────┤
LR RGB(보조 입력) ────┘
```

구조 변경 사항은 다음과 같습니다.

- PAN 1채널 입력부를 RGB 3채널 입력부로 변경합니다.
- 수 개의 MS 밴드를 처리하던 부분을 HSI 밴드 수에 맞게 변경합니다.
- 각 HSI 밴드와 RGB 특징의 관련성을 SSAI 방식으로 계산합니다.
- 최종 출력 채널을 HSI 밴드 수에 맞게 변경합니다.

핵심 가설은 SSAI가 각 HSI 밴드에 필요한 RGB 특징만 선택하고, 다중 해상도 융합이 큰 구조와 작은 경계를 단계적으로 복원하면 단순 확대보다 선명하면서 분광 왜곡이 적은 HSI를 만들 수 있다는 것입니다.

## 4. 데이터셋과 학습 데이터 구성

### ARAD-1K: 기본 학습 데이터

- 총 1,000개 장면
- 공개 GT HSI 950장: 공식 학습 900장, 공식 검증 50장
- 영상 크기: 482 × 512
- 31개 밴드: 400~700 nm, 10 nm 간격
- 나머지 시험 장면 50장의 GT HSI는 비공개

ARAD-1K의 HSI에서 카메라 분광응답을 적용해 HR-RGB를 만들고, blur와 downsampling으로 LR-HSI를 생성합니다.

```text
HR HSI(GT)
├─ 카메라 분광응답 적용 → 합성 HR RGB
└─ Blur + Downsample → LR HSI

입력: 합성 HR RGB + LR HSI
정답: 원본 HR HSI
```

RGB는 HSI에서 임의의 세 밴드를 고르는 대신 카메라의 RGB 분광응답을 여러 밴드에 적용합니다. LR-HSI도 단순 축소가 아니라 흐림을 적용한 후 축소합니다.

### PCB-Vision: 확보한 실제 RGB–HSI 데이터

[PCB-Vision](https://github.com/Elias-Arbash/PCBVision)은 실제 RGB 카메라 영상과 대응하는 HSI 큐브로 구성된 53개 PCB 장면 데이터셋입니다. HSI는 400~1000 nm의 VNIR 범위에서 224개 밴드를 제공합니다.

실제 데이터는 다음 두 방식 중 하나로 활용할 수 있습니다.

#### 방안 A — 실제 데이터 검증 세트

- ARAD-1K의 1,000개 장면을 중심으로 모델을 학습합니다.
- PCB-Vision은 실제 센서 영상에서의 일반화 성능을 확인하는 외부 검증 또는 시험 데이터로 사용합니다.
- 합성 데이터 성능과 실제 데이터 성능을 분리해 보고합니다.
- ARAD-1K와 PCB-Vision의 밴드 범위가 다르므로 공통 파장대 선택 또는 spectral resampling 기준을 먼저 정합니다.

#### 방안 B — 고해상도 실제 영상을 패치로 분할해 추가 학습

- 실제 RGB–HSI 장면은 해상도가 높으므로 정합된 영역을 여러 패치로 나누어 학습 샘플 수를 늘립니다.
- 전체 장면을 먼저 학습·검증·시험 세트로 분리한 뒤 각 장면에서 패치를 추출합니다.
- 같은 원본 장면의 패치가 서로 다른 세트에 섞이지 않도록 해 데이터 누수를 방지합니다.
- 겹치는 패치를 사용할 경우 stride와 중복 비율을 기록하고, 배경 비중이 지나치게 큰 패치는 제외합니다.
- PCB 장면에 편중될 수 있으므로 ARAD-1K와 실제 데이터의 배치 비율을 실험 설정에 명시합니다.

두 방안을 모두 시험할 수 있으며, 최종적으로는 `ARAD-1K 학습 → PCB-Vision 실제 검증`과 `ARAD-1K + PCB-Vision 패치 학습`의 결과를 비교해 실제 데이터 활용 방식을 결정합니다.

### 권장 데이터 분할

#### ARAD-1K

- 학습: 공식 학습 데이터 중 850장
- 내부 검증: 공식 학습 데이터 중 50장
- 최종 시험: 공식 검증 데이터 50장

#### PCB-Vision

- 방안 A: 장면 단위로 실제 검증·시험 세트 구성
- 방안 B: 장면 단위 분할 후 학습 장면에서만 패치 추출
- 정확한 장면 수와 비율은 실제 정합 품질을 확인한 뒤 확정

### 시각화 코드

- [`scripts/visualize_arad_hsi.py`](./scripts/visualize_arad_hsi.py): ARAD 형식 HSI 큐브에 CIE 1931 근사를 적용해 sRGB와 밴드·분광 곡선을 시각화합니다.

이 출력은 실제 RGB 카메라 측정값이 아니라 **HSI 시각화용 근사 RGB**입니다. RGB–HSI 융합 모델의 실제 RGB 입력으로 간주하지 않습니다.

## 5. 실험 및 평가 계획

### 기본 조건

- 우선 ×4 공간 해상도 복원을 목표로 합니다.
- 모든 모델에 같은 RGB 생성법, HSI 열화 방식과 데이터 분할을 적용합니다.
- 장면을 먼저 분리한 뒤 패치를 추출합니다.
- 합성 데이터 결과와 실제 데이터 결과를 별도로 제시합니다.

### 비교 대상

1. **Bicubic:** LR-HSI만 단순 확대합니다.
2. **기본 RGB–HSI CNN:** 확대된 HSI와 HR-RGB를 함께 입력합니다.
3. **SSA-MRN 기반 RGB–HSI 모델:** 밴드별 어텐션과 다중 해상도 융합을 적용합니다.

### 평가 지표

- PSNR: 전체적인 수치 오차
- SSIM: 경계와 구조의 유사도
- SAM: 픽셀별 분광 벡터의 각도, 낮을수록 좋음
- ERGAS: 여러 밴드의 상대적 복원 오차, 낮을수록 좋음

PSNR·SSIM이 좋아져도 SAM이 나빠지면 시각적으로 선명하지만 분광 정보가 왜곡된 결과일 수 있으므로 공간 품질과 분광 품질을 함께 평가합니다.

### 제거 실험

- SSAI 제거: 밴드별 어텐션 효과 확인
- 다중 해상도 융합 제거: 점진적 융합 효과 확인
- 실제 데이터 패치 추가 전후 비교

## 6. 차별점과 주장 범위

RGB 유도 HSI 초해상도 자체는 이미 연구된 분야이므로 ‘최초의 RGB–HSI 융합’으로 주장하지 않습니다. 기여 범위는 다음과 같이 한정합니다.

- 위성 펜샤프닝용 SSA-MRN을 일반 RGB–HSI 복원 문제로 확장
- PAN 대신 RGB의 다채널 공간 특징 사용
- HSI 밴드마다 RGB 특징과의 관련성을 계산해 불필요한 질감 전달을 줄이는지 검증
- 같은 조건에서 단순 보간·단순 융합·제안 모델을 정량 비교
- 합성 데이터 학습 결과를 실제 RGB–HSI 데이터로 검증하거나 실제 패치 학습으로 확장

## 7. 예상 한계와 주의점

- ARAD-1K에서 만든 RGB와 LR-HSI는 완벽히 정렬된 합성 입력입니다.
- 실제 데이터는 정합 오차, 노이즈, 시점, 초점과 촬영 시각 차이를 포함할 수 있습니다.
- ARAD-1K와 PCB-Vision은 장면 종류와 파장 범위가 다르므로 도메인 차이를 고려해야 합니다.
- 고해상도 장면을 많은 패치로 나눠도 독립된 장면 수가 늘어나는 것은 아닙니다. 평가는 반드시 장면 단위로 분리합니다.
- 공식 SSA-MRN 저장소는 핵심 네트워크를 제공하지만 완전한 학습·평가 파이프라인과 사전학습 가중치는 제공하지 않습니다.
