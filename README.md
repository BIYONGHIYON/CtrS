# CtrS

동국대학교 종합설계 팀 연구 저장소입니다. 현재는 두 연구 후보를 병렬로 개발하고, 중간 성과를 비교한 뒤 최종 주제 하나를 선택하는 단계입니다.

## 연구 운영 방식

1. **SSA-MRN 트랙**과 **ECRformer 트랙**을 각각 독립적으로 구현·검증합니다.
2. 중간 시점에 데이터 현실성, 재현성, 정량 성능, 정성 결과, 구현 난도, 계산 비용을 같은 기준으로 비교합니다.
3. 비교 결과가 더 좋은 주제를 최종 주제로 선정합니다.
4. 최종 선정 후에는 팀원 4인이 하나의 주제에 집중하여 모델 개선, 추가 실험, 시연 및 보고서를 함께 완성합니다.

## 연구 후보

### 1. SSA-MRN

고해상도 RGB의 공간 정보와 저해상도 HSI의 분광 정보를 결합해 고해상도 HSI를 복원하는 연구입니다. SSA-MRN의 밴드별 spectral-spatial attention과 다중 해상도 융합 구조를 RGB 유도 HSI 초해상도 문제에 확장합니다.

현재는 HSI로부터 RGB를 합성한 데이터와 실제 RGB 카메라 데이터의 차이를 주요 연구 위험으로 보고 있습니다. 합성 조건에서의 성능뿐 아니라 실제 센서 데이터 적용 가능성과 RGB-HSI 정합 문제도 함께 검토합니다.

### 2. ECRformer

광학 영상과 SAR 영상을 이용한 위성영상 구름 제거 연구입니다. ECRformer를 기반으로 Spectral-Semantic Decoupled Learning과 spectral fidelity 제약을 적용·확장하고, 구조 복원과 분광 정보 보존을 함께 평가합니다.

## 중간 선택 기준

- 데이터셋의 실제성 및 확보 가능성
- 기존 코드의 재현 가능성
- PSNR, SSIM, SAM 등 정량 성능
- 시각적 복원 품질과 오류 사례
- 제거 실험을 통한 제안 요소의 효과
- 학기 내 구현·학습·시연 가능성
- GPU 메모리, 학습 시간 및 팀 협업 난도

## 폴더 구조

```text
CtrS/
├── SSA-MRN/
│   ├── configs/       # 학습·평가 설정
│   ├── data/          # 로컬 데이터셋; Git에 포함하지 않음
│   ├── docs/          # 연구 계획, 회의 및 분석 문서
│   ├── experiments/   # 체크포인트, 로그 및 결과
│   ├── notebooks/     # 탐색 및 시각화 노트북
│   ├── references/    # 논문·공식 구현 정리
│   ├── scripts/       # 데이터 준비 및 실행 스크립트
│   ├── src/           # 모델과 학습 코드
│   └── tests/         # 단위·통합 검사
└── ECRformer/
    └── ...            # 동일한 구조 사용
```

대용량 데이터셋, 학습 체크포인트, 로그 및 생성 결과는 저장소에 직접 올리지 않습니다. 필요한 다운로드 경로와 재현 방법은 각 연구 폴더의 README에 기록합니다.
